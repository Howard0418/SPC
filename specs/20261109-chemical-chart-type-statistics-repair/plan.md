# 實作計畫

1. 以固定工作代號的 Receipt 鎖定 493 筆統計工作，不用日期或全表失敗狀態猜測範圍。
2. 對 25 個空圖型 PPC 建立證據集合；只接受唯一、啟用中的 `I_MR`。
3. planner 先驗證空值、冪等、覆蓋拒絕、缺證據及混合證據。
4. 測試環境先驗證同自然鍵與圖型資料；正式套用前另行授權、備份及重驗實際資料庫。
5. 正式套用採單一受控交易，僅更新 25 個 `ChartTypeId`，再把固定批次的 160 筆失敗工作排入重試；失敗則回復交易或依保存的 before 證據回復。
6. 驗證 160 筆完成、493 筆量測與追溯指紋不變、圖表服務可查詢；不發布網站。

## 風險檢查

- Happy Path：25 項唯一 I-MR、160 筆全數完成。
- Boundary：已是 I-MR 時重送 0 異動。
- Invalid：非空其他圖型、缺候選、混合候選、項目數或工作數漂移即停止。
- Regression：量測、公式、F、收據、排程、非目標 PPC 及網站保持。
