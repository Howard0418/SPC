# 藥液空白濃度公式保留未設定

- 功能 ID：SPC-CHEM-UNSET-20261105；版本 1；狀態：測試完成，正式待授權。
- 授權：使用者要求空白濃度公式不要補 `ROUND((0)+(1*Primary)+(0*Secondary),8)`，顯示未設定。
- 主系統 SPC；相依 Portal 舊規則來源與量測直接輸入；不變更 schema。
- 現況：ChemicalFormulaMigration 對每條舊規則無條件以係數產生公式；SourceFormula=直接量測值亦產生假公式。總覽已有空白顯示「未設定」。

## 需求與 BDD

- R1／AC1：Given 來源公式空白、空白字元或「直接量測值」，When 轉換，Then 濃度公式為空且不得啟用公式計算。
- R2／AC2：Given 來源有實際公式（即使結果等於 Primary），When 轉換，Then 保留既有轉換行為，不憑係數刪除真公式。
- R3／AC3：Given 既有設定具有 migratedFrom 且來源可確認為未設定，濃度為精確自動生成恆等式、複驗無其他真公式，When 測試區清理，Then 清空初複驗恆等式並停用公式計算、保留其他設定、新增公式版本。
- R4／AC4：Given 缺來源證據、有效公式、複驗有不同公式或來源鍵重複，When 清理，Then 保持原設定或整批拒絕。
- R5／AC5：Given 清理完成，When 重送，Then 0 異動；歷史量測、Receipt／Trace、F及排程不改。

## 範圍與驗證

先建核心單元測試，再修正工具及測試主檔。API／前端已有正確空白行為時不另發布程式。正式僅唯讀盤點，正式主檔清理另依已準備的清單取得發布／資料授權。評估正常、空白、有效恆等式、複驗、無來源及冪等回歸。
