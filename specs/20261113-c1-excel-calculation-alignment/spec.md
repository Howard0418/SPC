# 功能規格：C1 藥液計算與 Excel 對齊

- 功能 ID：`SPC-CHEM-C1-EXCEL-ALIGN-1113-TASK-001`
- 版本：2
- 狀態：完成
- 涉及專案：SPC（主系統）；Portal 僅顯示 SPC 計算與追溯結果，不修改程式
- 授權依據：使用者要求確認小數差異並修正為與 Excel 相同
- 現行需求基準：`specs/20261113-chemical-entry-per-item-precision/spec.md`
- 前案：`specs/20261103-chemical-formula-inventory/spec.md`

## 目的、現況與證據

2026-11-12 C1 開線資料與 Excel 不一致。唯讀核對原始活頁簿（SHA-256 `DF036AA58AD6358AD858D7A1F45256D887480F14DE9337D2B8B21E37FF2DAC1B`）及測試庫 Receipt 後確認：

1. C1 六個公式項目的 `decimalPlaces=2`，使 172.2105、152.8065 先取兩位後再顯示三位。
2. 鍍銅1氯離子 Excel 的 30.096 依公式 `Primary*152` 反推原始滴定值為 0.198；目前 Receipt 保存字串為 0.20，故算成 30.400。
3. 鍍銅1硫酸 Excel 以 Target 180 計算 20.7 L；目前調整式誤用 185／205，算成 34 L。

## 範圍與非範圍

- 測試庫六個 C1 公式項目建立新不可變公式版本，濃度保存精度改為三位。
- 鍍銅1硫酸的調整／調整量界線改為 Excel 的 180／195。
- 新增排程修訂，自 2026-11-12 00:00（台北）起套用新版本，舊期間與舊證據保持。
- 受控校正 2026-11-12 開線六筆目前值；鍍銅1氯離子以真實原始滴定值 0.198 重算，建立新 Receipt／Trace。
- 不改 schema、Portal／SPC 網站程式、正式資料庫、其他線別／日期或原 Excel。

## BDD

- Given C1 鍍銅1硫酸滴定值7.10與F B3=0.99，When 依11/12公式預覽，Then Raw=172.2105且Stored=172.211。
- Given Excel 氯離子畫面顯示0.20但濃度為30.096，When 讀取其公式與未顯示原始精度，Then SPC 保存0.198並算得30.096，而不是以0.20算30.400。
- Given 11/12已有兩位先取整的Receipt，When 受控修正，Then 舊證據不覆寫，新Trace v2成為目前有效結果。
- Given 修正已完成，When 重跑同一工具，Then 不新增任何版本、排程或追溯資料。

## 例外與邊界

- PPC身分、既有公式、F247、排程、量測ID、舊Receipt／Trace或預期值漂移即停止。
- 除精度、鍍銅1硫酸調整式及指定氯離子原始值外，不自動改寫其他公式內容。
- 備份或驗證失敗時不寫入。

## 假設與未決問題

無阻擋未決問題。0.198由 Excel 固定公式 `Primary*152` 與結果30.096唯一反推，並符合使用者提供的當日報表證據。
