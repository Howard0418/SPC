# 功能規格：SPC 藥液匯入資料移轉正式庫
- 功能 ID：20260910-chemical-production-transfer
- 版本：1
- 狀態：實作中
- 涉及專案：SPC
- 授權依據：使用者「同意，並移轉」，同意前述僅新增、限定藥液匯入資料建議。
- 現行需求基準：[需求索引](../../docs/requirements.md)

## 目的、現況與證據
依 CHANGELOG_CUSTOM.md，測試庫於 9/8 追加 1,269 筆 8 月非 N1/N2 藥液資料，正式庫已有部分 8、9 月資料；實際差異以本次唯讀盤點為準。
既有 UploadService 支援 insertOnly，但有自動建立人員、主檔及寄送異常信件的副作用；執行前須確認不會超出本次資料範圍。

## 範圍與非範圍
只移轉測試 SPC 已匯入且可追溯來源批次的 CHEM 藥液量測及必要新批次稽核；測試資料保留。
排除手動量測、測試產生資料、其他管制類型、人員、權限、設定、主檔、公式，以及其他專案資料。
不覆寫或刪除正式既有量測，不搬移測試計算與警示；如需計算僅依正式規格處理新增資料，不寄送通知。

## 需求與驗收
| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|
| R-001 | 確認來源與正式目標 | AC-001 | 實際連線查明伺服器、資料庫、schema 與批次 |
| R-002 | 僅 CHEM 匯入來源 | AC-002 | 差異清單有來源批次、量測 ID、對應與排除原因 |
| R-003 | 僅新增、保留班別及原值 | AC-003 | 同鍵略過，衝突及缺少主檔列出；新增值逐筆核對 |
| R-004 | 不改其他資料 | AC-004 | 正式既有資料及非允許資料表前後比對不變 |
| R-005 | 可復原與追溯 | AC-005 | 完整備份與驗證成功後才寫入，記錄新批次及 ID |

## 例外與邊界
缺少或多重主檔對應、同鍵不同值、來源不明均略過並記錄，不自動補主檔。
連線或備份失敗不得進行正式寫入；交易失敗回復交易。

## 假設與未決問題
預期 PMR_SPC_TEST → PMR_SPC_2026，須以實際連線驗證；不沿用舊筆數作驗收。
