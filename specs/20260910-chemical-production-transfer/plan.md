# 技術計畫
- 功能 ID：20260910-chemical-production-transfer
- 規格版本：1
- 規格：[spec.md](spec.md)

## 系統責任與受影響檔案
SPC 受控資料移轉工具及本規格文件；不修改 Portal 或 TransFiles。

## 實作方式與需求對應
先唯讀盤點兩庫來源、schema、量測與對應主檔。以正式業務代碼及單位唯一對應，不直接沿用測試 ID。
產生新增、已存在、衝突、缺少對應清單。使用既有匯入服務前檢查其副作用，以交易與資料表不變驗證限制範圍；無法滿足時採受控 EF 寫入，保留必要批次追溯，不改 schema。

## API、檔案格式及資料模型
日報鍵為正式管制項目、PortalDailyDate、SamplingPhase；非日報依現有匯入唯一識別與來源證據判定。
報告存本規格資料夾；不輸出連線密碼。

## 相容性與風險
須實際確認正式欄位支援；原始匯入 payload 與現存量測不同時不可直接重播舊值。禁止搬移人員、規格與公式，不觸發通知。

## 驗證安排
AC-001～005：連線辨識、來源盤點、逐筆差異、備份驗證、交易內前後完整性檢查、提交後重新查核。
工具新增的篩選與比對行為須有自測；無應用程式邏輯修改，不執行不相關測試。

## 發布、備份及回復
僅資料移轉，無 IIS 發布。正式庫 COPY_ONLY、CHECKSUM 完整備份並 RESTORE VERIFYONLY 成功後才新增。
提交前異常使用交易回滾；提交後優先依本次批次與新增 ID 受控回復，不影響其他期間寫入；完整備份還原須另行核對影響。
