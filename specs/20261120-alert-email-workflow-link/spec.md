# OOS／OOC 郵件連到管制圖與異常處置

- 工作：`SPC-ALERT-MAIL-WORKFLOW-1120-TASK-001`，P1／SPC Web、API；依據：2026-11-20 使用者收到 OOS／OOC 郵件後提出。
- 狀態：規格 v2 已發布 SPC 測試站，待使用真實警報進行登入驗收。
- 正常 OOS／OOC 郵件加入環境專屬 HTTPS 連結及警報 ID。點擊使用既有 SPC 登入、頁面權限和異常處置流程；不在網址傳送身分、憑證、量測值或處置內容。
- 深連結先載入與選單直接進入相同的完整異常處置清單，再讀取單筆警報，包含舊於 500 筆列表限制或已結案者；目標不在清單時合併補入，切換至其狀態分類、捲動並醒目定位。目標列沿用既有管制圖連結與處置入口，不另顯示專用版面或內嵌圖表。
- Given 有權限的使用者收到警報，When 點擊郵件連結，Then 登入後定位該筆警報，查看對應管制圖，可輸入真因、對策、負責人或狀態，保存並重載確認。原本列表、圖表與公式通知繼續使用既有流程。
- Given 無權限、警報不存在、或缺少可唯一定位的圖表，Then 由既有權限檢核或明確提示處理；不猜測圖表、不寫入其他警報。
- 測試：郵件連結環境、單筆定位、無圖情境、保存／重載、既有頁面回歸；SPC 測試站版本遞增，正式須另行授權。無 schema migration，回復前版 API／Web 資產。
