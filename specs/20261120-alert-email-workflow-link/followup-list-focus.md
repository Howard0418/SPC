# 郵件深連結沿用異常單簽核處置清單版面

- 工作：`SPC-ALERT-MAIL-WORKFLOW-1120-TASK-001` 後續修正，規格版本 v2。
- 狀態：2026-11-20 測試站發布、自動化及使用者真實郵件連結人工驗收通過，DONE；正式站未發布。
- 需求：郵件連結進入後，必須與從選單直接點擊「異常單簽核處置」看到相同的完整清單頁；不得切換成單筆專用版面或在清單上方內嵌另一張管制圖。
- Given 使用者由 OOS／OOC 郵件開啟有效 `alertId`，When 完成登入並進入 `/alerts-workflow`，Then 載入既有異常清單、篩選器、統計及操作欄，切到目標警報所屬狀態，捲動並醒目定位該列。
- Given 目標警報不在既有清單回傳範圍內，When 單筆警報查詢成功，Then 將該筆合併至清單後定位，不移除其他清單資料、不重複同一 ID。
- Given `alertId` 無效或查無資料，Then 保留完整清單頁並顯示既有明確錯誤，不猜測或定位其他警報。
- 目標列仍沿用既有「查看 SPC 圖表」與「檢視／修改」操作，可輸入並保存異常處置；API、權限、資料庫與郵件網址格式不變。
- 驗證：Playwright 覆蓋直接進入與郵件進入的相同清單結構、目標不在前 500 筆仍合併定位、無內嵌專用圖表、處置保存重載及既有 Alerts 回歸。Web／API 發布版本依共用規則遞增，發布測試站後驗證資產 MIME、health、version、環境與瀏覽器實際 API 基底；正式站不發布。
- 回復：回復前版 Web 資產及 API 版本標記；無 schema 或資料回復。
