# 功能規格：公式儲存後管制圖即時重載

- 功能 ID：`SPC-CONTROL-CHART-AUTO-REFRESH-1111-TASK-001`
- 版本：1
- 狀態：實作中
- 涉及專案：SPC
- 授權依據：使用者於 2026-11-11 明示「按儲存後，畫面上的既開圖表要立即自動更新，此項請先執行」。
- 現行需求基準：[管制線公式續驗](../20261029-control-line-formula-recalc/followup-20261102.md)
- 前案或相關規格：`SPC-ADJUST-1028-TASK-001`。

## 目的、現況與證據

後端已在公式 JSON 有實質差異時清除同一 PPC 的舊計算快取，下一次圖表查詢會重算；但既開啟的圖表頁沒有收到通知，使用者必須手動重新查詢。本件補足前端更新通知，令已開啟且對應同一 PPC 的管制圖／趨勢圖立即重載。

## 範圍與非範圍

- 範圍：PPC 儲存成功後發布同源更新通知；開啟中的同 PPC 圖表接收後重新呼叫既有查詢並重繪。
- 非範圍：不變更公式計算、量測、快取刪除規則、資料庫、API 契約、圖表選項或其他 PPC 圖表。

## 需求與驗收

| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|
| R-001 | 公式儲存成功後，該 PPC 的既開圖表須立即重新查詢。 | AC-001 | 同頁或另一同源分頁的同 PPC 圖表發出 `/v1/spc/chart` 新查詢並重繪。 |
| R-002 | 通知不得誤重載其他 PPC，儲存失敗不得觸發。 | AC-002 | 不同 PPC 忽略通知；API 儲存失敗時不發布通知。 |
| R-003 | 舊瀏覽器或通知通道不可用時，儲存與既有手動重查詢仍可用。 | AC-003 | BroadcastChannel／storage 例外被安全隔離，既有儲存流程不受阻。 |

## 例外與邊界

- 只有 API 儲存成功且有有效 PPC ID 才通知。
- 目前無圖表或正在顯示其他 PPC 時，不進行請求。
- 批次上傳圖表沿用其現有 batch 查詢路徑。

## 假設與未決問題

無阻擋性問題；同源分頁以 `BroadcastChannel` 通知，並以瀏覽器 `storage` 事件作相容備援。
