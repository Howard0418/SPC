## 目的、現況與證據

### 功能目的與分工
- **SPC**：儀器主檔、校正紀錄、到期判斷與通知排程；資料唯一來源。
- **Portal**：首頁顯示即將到期、已逾期摘要，並提供進入 SPC 的連結；不維護第二份儀器資料。

- 主檔：製程、生產機台、槽體、管制項目、`Operators`（Email、角色）。儀器與 `Machines` 分開建檔。

## 例外與邊界
- 編號重複、必填缺失、下次日期不晚於上次：拒絕。
- 證書第一版：PDF／JPEG／PNG，單檔 10 MB，私有目錄授權下載。
- SMTP 未設定或 `Calibration:DeliveryEnabled` 未開：記失敗，不連到外部亂寄。
- 投遞結果不確定（timeout 等）：標 `Unknown`，不自動當成功重寄。
- 量測 API 不因本模組回傳失敗。

## 決議規則（2026-09-11 使用者同意建議方案）

### 決議一（Q-01）
時區 `Asia/Taipei`／`DateOnly`。即將到期：`今日 <= 下次日期 <= 今日 + max(提醒天數)`（預設 max=30）。到期當日仍為即將到期。已逾期：`下次日期 < 今日`。畫面與信件日期為台北日。每日台北 08:00 起掃描。

### 決議二（Q-02）
逾期第 1 天寄一封；之後每 7 天一封，直至合格校正或停用／報廢。第一版無主管升級。逾期階段不寫入 R-004 可設定天數。

### 決議三（Q-03）
週期單位為月。合格後 `下次日期 = 本次校正日 + 月數`（`AddMonths` 月底對齊）。人工調整下次日期必填原因並寫入異動。上次日期可空，下次日期必填。

### 決議四（Q-04）
狀態碼：正常 `Active`、送校中 `InCalibration`、停用 `Inactive`、報廢 `Retired`。送校中：摘要可計入即將到期／已逾期，暫停到期信。不合格：保存紀錄與證書，不延長下次日期。不阻擋量測。

### 決議五（Q-05）
SPC `Viewer` 查詢；`Editor` 具 `calibration.manage` 可維護（未自訂 `PagePermissionsJson` 的 Editor 與現有系統相同，預設含該頁）。Portal 僅品保看摘要，不過濾部門。收件人為系統內啟用且 Email 有效者；預設包含保管人，可取消；可另指定多人。不含外部信箱。

### 決議六（Q-06）
唯一鍵 `(InstrumentId, CycleId, DueDate, Stage, RecipientKey)`。`Sent` 或處理中不重寄。初次失敗後最多再試 3 次，間隔 15 分、1 小時、4 小時；之後不再排程。完成校正或改到期日則取消 Pending／Failed。不合併 digest。
