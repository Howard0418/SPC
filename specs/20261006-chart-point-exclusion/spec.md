# SPC 管制圖/趨勢圖點位排除與隱藏規格

- 功能 ID：SPC-POINT-FILTER
- 版本：1
- 狀態：規劃完成，待實作
- 日期：2026-10-06
- 授權依據：使用者要求在管制圖與趨勢圖量測點右鍵顯示選單，提供「顯示但不列入計算」與「隱藏且不列入計算」，並確認隱藏後須有恢復入口。

## 背景與現況

- 現有後端已有 `UploadBatches.IsExcluded`，`POST /api/v1/spc/exclude-batch/{uploadBatchId}` 會切換整批上傳資料的排除狀態。
- 現有 `SpcDataPoint`、`Subgroup`、`AttributeDataPoint` 已有 `isExcluded`，I-MR、Xbar-R、Xbar-S、Attribute chart 與常態檢定會排除 `isExcluded` 點。
- 現有管制圖點位明細有「剔除此數據 / 恢復此數據」按鈕，但實際是依 `measurementBatchId` 或 `uploadBatchId` 切換整批，不是單一點位。
- 現有趨勢圖可顯示 `isExcluded` 狀態，但沒有右鍵選單、沒有設定/恢復操作。
- 現有功能沒有「隱藏但可從清單恢復」的資料狀態與畫面入口。

## 問題

整批排除無法滿足使用者要在單一量測點右鍵處理的需求；若只在前端隱藏點，後端統計仍會列入計算，會造成圖表、直方圖、P-value、能力指標與總覽口徑不一致。

## 目標行為

- 使用者可在管制圖與趨勢圖的量測點按右鍵開啟選單。
- 選單提供：
  - 顯示但不列入計算。
  - 隱藏且不列入計算。
  - 已排除點可恢復為正常列入計算。
- 「顯示但不列入計算」的點仍在圖上顯示，需以灰色、空心或特殊符號標示。
- 「隱藏且不列入計算」的點不出現在圖上，但必須出現在「已排除點」清單，可從清單恢復。
- 管制圖、趨勢圖、直方圖、常態檢定、能力指標、OOS/OOC 統計皆以後端排除狀態為準。
- 不刪除原始量測資料，不修改原始量測值。

## 非範圍

- 不變更既有原始量測資料結構或歷史量測值。
- 不取消既有整批 UploadBatch 排除功能；後續實作需評估是否保留為批次工具。
- 不在本規劃階段修改程式、migration 或測試站。

## 狀態定義

- `Normal`：正常顯示，列入計算。
- `ExcludedVisible`：顯示但不列入計算。
- `ExcludedHidden`：隱藏且不列入計算。

## 恢復入口

- 管制圖與趨勢圖工具列新增「已排除點」按鈕，顯示數量，例如 `已排除點 3`。
- 點開後列出目前查詢條件下被排除的點：
  - 量測時間
  - 線別/槽位/分析項目
  - 原始值
  - 狀態
  - 修改人
  - 修改時間
  - 備註
  - `恢復` 按鈕
- Raw data 或點位明細清單須能看見被隱藏點，並可恢復。
- 圖上仍顯示的 `ExcludedVisible` 點可由右鍵或點位明細恢復。
- 圖上不顯示的 `ExcludedHidden` 點只能由「已排除點」清單或 raw data/明細清單恢復。

## 需求

- R-001：系統須能記錄單一量測點的排除狀態，不得只依整批 UploadBatch。
- R-002：排除狀態須包含 `Normal`、`ExcludedVisible`、`ExcludedHidden`。
- R-003：管制圖與趨勢圖統計計算須排除 `ExcludedVisible` 與 `ExcludedHidden`。
- R-004：`ExcludedVisible` 點仍顯示在圖上，但以明確樣式標示不列入計算。
- R-005：`ExcludedHidden` 點不顯示在圖上，但須在「已排除點」清單與 raw data/明細中可恢復。
- R-006：恢復後點回到 `Normal`，圖表與統計重新計算。
- R-007：排除/恢復須記錄操作者、時間、狀態、來源點與可選備註。
- R-008：權限不得大於既有 SPC 管理/編輯權限；一般查詢者不可變更排除狀態。
- R-009：製程與藥液皆適用；不可影響藥液既有資料計算與製程總覽已修正口徑。

## 驗收

- AC-001：現況分析確認管制圖/趨勢圖點位來源、穩定 ID 與目前排除機制。
- AC-002：新增資料模型/API 後，單一點可設定 `ExcludedVisible`、`ExcludedHidden` 與恢復。
- AC-003：管制圖排除單一點後，平均、標準差、能力指標、OOS/OOC 與規則判定依排除後資料重新計算。
- AC-004：趨勢圖排除單一點後，折線圖、直方圖、P-value 與統計狀態依排除後資料重新計算。
- AC-005：隱藏點在圖上消失，但可在「已排除點」清單找到並恢復。
- AC-006：重新整理頁面後，排除/隱藏狀態仍存在。
- AC-007：權限測試通過，未授權者不能變更點位狀態。

## 未決與假設

- 假設優先支援 VariableMeasurement 與 Xbar 子組點位；AttributeMeasurement 需在模型設計時一併保留欄位。
- Xbar-R/Xbar-S 的右鍵點位代表「子組點」。實作前須決定排除一個子組時，是排除該時間子組所有 raw samples，還是只排除該圖上的聚合點。建議以「圖上子組點」為單位，並記錄對應 raw measurement IDs。
- 若一個圖點對應多筆 raw data，恢復也以同一個圖點狀態恢復，不逐筆拆開，避免 UI 與計算口徑混亂。

## Rollback

- 規劃階段 rollback：移除本規格與 TODO 內新增項目即可。
- 實作後 rollback 原則：先停用新 UI 與 API，再依 migration rollback 移除點位排除狀態資料；原始量測資料不受影響。
