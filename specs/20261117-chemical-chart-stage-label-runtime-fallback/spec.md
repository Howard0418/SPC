# 功能規格：藥液管制圖開收線標籤執行期回退
- 功能 ID：SPC-CHEM-CHART-STAGE-LABEL-1113-TASK-001-FIX-001
- 版本：1
- 狀態：測試站已修正，待登入畫面驗收
- 涉及專案：SPC 前端
- 授權依據：使用者於 2026-11-17 回報 N2／化鎳／PH 的 2026-11-04 開收線兩點皆顯示「早班」，並指示「請修正」。
- 現行需求基準：[藥液管制圖開收線辨識](../20261113-chemical-chart-stage-label/spec.md)
- 前案或相關規格：[前案驗證](../20261113-chemical-chart-stage-label/verification.md)

## 目的、現況與證據
測試資料庫的 PPC 2520（`CHEM`、機台 `N2`、化鎳／PH）在 2026-11-04 已保存兩筆不同階段：ID 92009 為 `OPEN`、值 8.420；ID 92019 為 `CLOSE`、值 8.400。使用者畫面仍將兩筆顯示為「早班」。

既有前端只有在已成功解析藥液主檔時才啟用階段標籤。圖表已回傳同日 `OPEN/CLOSE` 成對階段時，主檔投影暫時缺失不應使可辨識的階段退化為相同班別。

## 範圍與非範圍
- 範圍：調整 SPC 管制圖前端的階段標籤判定與回歸測試。
- 非範圍：不修改 API、資料庫、歷史量測、`SamplingPhase`、`SamplingStage`、圖表序列、MR、管制線、規格或能力指標；不發布正式站。

## 需求與驗收
| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|
| R-001 | 圖表回傳同日 `OPEN` 與 `CLOSE` 成對階段時，即使主檔對應尚未解析，仍以階段顯示，而非兩個「早班」。 | AC-001 | Given N2 11/04 的 8.420 `OPEN` 與 8.400 `CLOSE` 點，When 繪製 I-MR 圖，Then X 軸依序為 `11/04 早(開)`、`11/04 早(收)`。 |
| R-002 | 回退只套用於明確存在開、收成對階段的資料，不將單一、空白或 `GENERAL` 階段猜測為開收線。 | AC-002 | Given 沒有完整 `OPEN/CLOSE` 對的圖表，When 繪製，Then 原有班別顯示保持。 |
| R-003 | 本件只改顯示判定。 | AC-003 | 同一序列的點數、值、MR 與統計不變。 |

## 例外與邊界
- 僅有 `OPEN` 或僅有 `CLOSE` 的資料不啟用此回退。
- `GENERAL`、空白及未知階段不因本修正改名。
- 已正常解析主檔的 N1／N2 行為保持不變。

## 假設與未決問題
無。使用者截圖之實際瀏覽器工作階段無法由自動化工具連入，故完成後仍需使用者畫面驗收。
