# 正式 SPC 重複帳號整理任務
- 功能 ID：SPC-OPERATORS-MERGE-1125
- 規格版本：1
- [規格](spec.md)｜[計畫](plan.md)

同一件小工作的步驟。P1 待排程，與其他權限／SSO 高風險工作依序進行。

- [ ] T-001：正式唯讀定位兩筆，核對身分、引用及權限，確認是否升為 P0（AC-001、AC-002）。
- [ ] T-002：確認保留主檔與權限處置，隔離演練及驗證回復，準備核准資料（AC-003、AC-004）。
- [ ] T-003：核准後交易整理正式 SPC 個案，驗證唯一登入與關聯（AC-003、AC-004）。
- [ ] T-004：登錄實際驗收、結果及發布狀態。
