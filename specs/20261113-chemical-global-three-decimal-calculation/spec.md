# 功能規格：藥液滴定值與分析值統一三位計算
- 功能 ID：`SPC-CHEM-GLOBAL-3DP-1113-TASK-001`
- 版本：2
- 狀態：待人工驗收
- 涉及專案：SPC（主系統）、Portal（相依顯示）
- 授權依據：使用者確認「滴定值算到小數第3位，然後才算公式，算完後取到小數第3位」並要求先調整供驗證。
- 現行需求基準：藥液公式由 SPC 計算，Portal 顯示伺服器預覽結果；既有已保存歷史值不得批次重算。
- 前案或相關規格：`../20261113-chemical-entry-per-item-precision/`、`../20261113-c1-excel-calculation-alignment/`

## 目的、現況與證據

現行引擎將未取位的 Primary／Secondary 直接代入公式，最後再依各公式 `decimalPlaces`（多數為2）保存，因此未形成統一的三位計算鏈。使用者已確認新規則必須先將滴定值取至小數第3位，再計算並將分析值取至小數第3位。

## 範圍與非範圍

- 範圍：SPC 藥液初驗／複驗公式計算、Primary／Secondary 正規化、預覽回傳精度與計算證據版本。
- 相依：Portal 沿用 SPC 回傳的三位精度顯示與送出，不另建公式。
- 非範圍：不批次改寫既有量測、Receipt、Trace、公式內容、F表、規格上下限或正式站。
- 資料庫影響：無 schema migration、無本件資料修補。
- 發布影響：測試通過後發布 SPC 測試 API；Portal 若無程式異動則不發布。
- Rollback：回復本件程式版本並重新發布測試 API；既有資料未批次異動。

## BDD

- Given 滴定值為0.3524且公式為Primary*152，When 執行初驗預覽，Then 先得到0.352，再得到分析值53.504。
- Given 滴定值為0.3525，When 執行預覽，Then AwayFromZero得到0.353後才套公式。
- Given 第二滴定值與複驗公式，When 執行複驗預覽，Then兩個滴定值都先取三位且回傳三位分析值。

## 例外與邊界

- 空白、非數字、超出decimal精度仍依既有規則拒絕。
- 中點取位採 `MidpointRounding.AwayFromZero`，正負值一致。
- 判定與調整公式使用公式計算出的未顯示原始值；分析值保存則固定三位。

## 假設與未決問題

無阻擋問題。新規則只影響本次發布後的新預覽／重新計算；已保存歷史值維持可追溯。
