# SPC 管制項目設定漸進式載入

- 功能 ID：`SPC-PPC-LOAD-1109-TASK-001`
- 日期：2026-11-09
- 優先級：P1（高頻查詢效能）
- 狀態：測試站完成／正式未發布

## 現況與目的

「SPC 管制項目設定與規格維護」目前將管制項目主清單、12 組輔助主檔及初始製程篩選綁在同一次載入；任一輔助請求較慢時，主清單持續顯示載入中。正式站唯讀診斷顯示 API 單次回應正常，瓶頸在前端全有或全無的等待與大量清單繪製。

## 範圍

- 主清單完成後立即解除表格載入狀態並呈現資料。
- 輔助主檔維持並行載入，完成後更新名稱、篩選及編輯選項。
- 輔助主檔失敗須保留主清單，不得清空已成功資料；畫面仍顯示錯誤。
- 不修改 API、資料庫、查詢條件、排序、編輯與儲存 payload。
- 只發布 SPC 測試站；正式站須另行授權。

## BDD 驗收

```gherkin
Scenario: 主清單先於輔助主檔完成
  Given 管制項目主清單已回應且部分輔助主檔仍在等待
  When 頁面處理主清單回應
  Then 表格立即顯示主清單
  And 不等待所有輔助主檔才解除主清單載入狀態

Scenario: 輔助主檔失敗
  Given 主清單已成功顯示
  When 任一輔助主檔載入失敗
  Then 已顯示的主清單保持
  And 畫面顯示可理解的錯誤
```

## 驗證

- Happy path：主清單先完成，輔助資料稍後完成。
- Boundary：主清單與輔助資料同時完成。
- Invalid：主清單失敗；輔助資料失敗但主清單保持。
- Regression：前端漸進載入單元測試、i18n檢查、Release測試站建置及實際站台連線驗證。

## 回復

還原本件前端來源及測試站 Web 備份；無資料庫或 API 回復。

## 完成結果

- 主清單與輔助主檔改由可測試的漸進載入協調器處理，主清單完成即解除表格載入狀態。
- 輔助主檔失敗不會清空已成功主清單；錯誤仍由既有畫面顯示。
- 測試 Web `0.1.124` 已發布；正式未發布。完整證據見[驗證](verification.md)。
