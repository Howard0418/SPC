# 功能規格：藥液各分析項目小數精度
- 功能 ID：SPC-CHEM-PRECISION-1113-TASK-001
- 版本：1
- 狀態：實作中
- 涉及專案：SPC（主系統）、Portal（相依系統）
- 授權依據：2026-11-13 使用者確認選項 3：「各分析項目可設定第 3 或第 4 位」。
- 現行需求基準：[藥液最終分析值一致顯示](../20261113-chemical-effective-value-entry-display/spec.md)

## 目的、現況與證據

SPC 公式版本已有 `decimalPlaces` 設定，但 Portal 的 `ChemicalPrecision.set` 固定顯示 2 位，日報送出也固定用 `toFixed(3)`，造成設定第 4 位的分析值在畫面或 payload 被截斷。

## 範圍與非範圍

- 範圍：依每個分析項目的已發布公式精度（3 或 4）顯示滴定值／初驗／複驗／最終分析值，並以該精度送出直接輸入值。
- 範圍：SPC 預覽 API 回傳公式實際使用的精度，日期排程不同版本可依當次預覽正確顯示。
- 非範圍：不批次變更既有項目設定、不改寫歷史量測、不更動公式內容、schema 或正式站。

## 需求與驗收

| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|
| R-001 | 項目精度由已發布公式的 `decimalPlaces` 決定，作業人員可於 SPC 既有公式設定選 3 或 4。 | AC-001 | Given 公式設定 4，When 預覽，Then API 回傳 4 且分析值顯示四位。 |
| R-002 | 初驗、複驗、最終值與直接輸入送出不得因前端固定三位而截斷第 4 位。 | AC-002 | Given `12.3456`，When 輸入／送出，Then 顯示與 payload 保留 `12.3456`。 |
| R-003 | 歷史資料不重算／不寫回；既有 2 位設定仍可讀取。 | AC-003 | 載入歷史不發送 preview，且既有設定不因本次自動變更。 |

## 邊界與假設

- 此次只新增對 3、4 位設定的支援與測試；已有其他精度的歷史設定維持相容。
- 公式排程可隨日期換版，最終顯示以該次伺服器 preview 回傳精度為準。
