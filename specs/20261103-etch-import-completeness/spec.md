# 固定咬蝕匯入規則與完整性核對

ID：TRANSFILES-ETCH-1103-TASK-001；P0資料正確性；2026-11-03使用者要求將已核對規則寫入轉檔工具，以後不得漏匯。狀態：程式／測試／EXE與已核准正式API102／218及專用旗標已更新；原生GUI及正式登入後人工驗收保留待辦，整件未結案。詳[正式階段](formal-release.md)。

主系統TransFiles，相依SPC（嚴格匯入、既有資料核對）、Portal（沿用身分與雙站流程）。不變更schema、主檔、公式/F政策，不啟用排程、不重匯已完成歷史資料。正式網站發布及正式匯入開關沿既有另行授權規則，不隱含由修改工具直接啟用。

## 現行基準與需求

- 延續[11/03核對規則](../20261103-etch-missing-line-reconciliation/spec.md)：檔名唯一年份＋MMDD工作表；PT1/QE1每面25、PT2/QE2每面50；原始成對值與每點公式快取完整，速率為全點平均×實際線速／有效長度（PT .975、QE1 1.944、QE2 2.268）。一日線三項，不能將raw當子組趨勢。
- R1：區塊標題必須與固定線別一致；X標記排除、負值／缺值／格式／快取錯誤隔離。每張日期工作表四區塊都要登錄READY／EMPTY／EXCLUDED／QUARANTINED／FUTURE／OUT_OF_SCOPE，不得無紀錄消失；無效日期／非日期頁另列。明確起迄日含邊界，不能把年度檔的檔案勾選誤當工作表月份篩選。
- R2：保留完整原始精度與來源hash，確認前重驗來源未變。PT1 B44及PT2 H44漏取一列只能列平均公式警告，計算依完整25／50點，原檔不代改。摘要警告、來源阻擋、正常X排除分開計數。
- R3：跨檔同日線同內容只一份，保留重複來源；不同內容列衝突並阻擋確認。不因檔名或hash改變而重匯。僅檢查過、dry-run或preview過不能當已匯入，排程hash不得使未寫入資料永遠略過。
- R4：伺服器按原日線業務鍵檢查全部紀錄（含封存），核對原PPC、日期、實際機台／製程、SampleNo、完整原值及速率；已存在同內容只讀略過，不要求舊batch hash等於新序列化。部分、不同內容、跨PPC、封存等列衝突，不能補寫或覆寫。沿用機台專屬優先、唯一同線製程空機台fallback規則。
- R5：新資料仍走Portal雙站確認；SPC同日線交易／鎖、嚴格僅新增。前置preview與後置inspect均核對可信環境及筆數；每份確認後查回25／50＋速率，超時結果不確定不得直接宣稱成功。已存在且核對通過者不送confirm。
- R6：預覽中途錯誤可停止網路呼叫，但後續全列NOT_PROCESSED；結果逐份對帳，未處理／衝突／查回失敗不可併入成功。清楚區分「合格範圍完成」與全部來源；任何來源隔離時不得聲稱全來源無缺漏。保存安全JSON與CSV逐日線結果、來源完整性與公式警告，禁止帳密／token／cookie入紀錄。
- R7：實際GUI、手動匯入及既有排程預覽共用契約；舊輸出模式僅匯出、不得繞過完整日報寫入。交付有可見版本的新EXE與使用說明，保留舊EXE供回復，不能只改未封裝來源後稱工具已更新。
- R8（使用者11/03補充）：`PT-01-2`等明確線別後綴`-2`代表第二次量測，以第二次取代第一次。一般同次重送仍略過；同日線完整第二次只可受控取代已確認第一次，保留原ID、第一批與Before來源／原值，重送第二次不再寫入，第一次不得反蓋第二次。同次內容不同、未知舊次數且內容不同仍隔離，不當任意覆寫許可。原溫度註記如`PT-01(27度)`不改線別，原文保留。10/16既有資料先唯讀核對是否已是第二次。
