# SPC-CHEM-CURRENT-ADJUST-1124 Portal 採 SPC 現行調整公式

Portal 新預覽與確認時，調整、調整量及其槽容／管制值取同項目的 SPC 已儲存設定，與量測日期無關。濃度、F 表及規格仍按原排程與日期。舊日報保存值及既有憑證保留。TransFiles 與一般日期公式 API 保留原契約。調整公式儲存不再建立日期排程。Portal 草稿偵測到現行設定變更後重算；確認憑證包含實際採用的兩式與參數。

Given 舊排程按 Target 60，現行調整式固定 100，When Portal 用該日期試算，Then 使用現行兩式與參數。歷史濃度維持。Given 修改現行兩式，When 重送舊預覽，Then 系統要求重新預覽。無有效濃度排程時維持原有驗證。削除正式內容另行授權。
