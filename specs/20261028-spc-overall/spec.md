# 功能規格：Overall 管制與異常處置總覽
- 功能 ID：SPC-OVERALL-001
- 版本：1
- 狀態：完成
- 主系統：SPC；相依系統：無；資料庫 migration：無。
- 授權：使用者確認同時顯示異常項目數／點位件數、處置去重與日期區間。
- 基準：[需求索引](../../docs/requirements.md)、既有 SPC 管制圖與異常處置流程。

## 現況與範圍
首頁導向 /spc，舊 Dashboard 未掛路由，不修改該閒置頁。於 /spc 新增獨立 Overall 區塊，不受下方單一維度／線別選擇限制。全部啟用管制項目為監控母體（包含無量測者），另揭露停用數；不改既有公式、規則、寫入、權限或其他系統。
告警單一 AlertType 無法表達同點 OOC+OOS，且列表僅取500筆，不以該列表直接加總。沿用現行互動圖表引擎取得全部啟用項目的判定，Overall 不套用舊圖表1000筆截斷；舊圖表行為保持。

## 需求與 BDD 驗收
|需求|規則|驗收|Given / When / Then|
|---|---|---|---|
|R-001|母體含所有啟用項目，顯示登錄總數及停用數|AC-001|Given 10啟用、2停用且部分無量測，When 查詢，Then 管制項目10、登錄12、停用2。|
|R-002|OOC／OOS分別顯示項目數與件數|AC-002|Given A有3個OOC、B有2個OOC，When 查詢，Then OOC為2項／5件；同一點兼OOS可在兩類各計1，但案件合計只計1。|
|R-003|異常點位去重後統計處置|AC-003|Given 同點同時OOC／OOS或重複告警，When 查詢，Then 只算一件；最新處置狀態Closed或既有IsAcknowledged算已處置，Open／InProgress／無告警算未完成處置。子組需所有關聯異常案件均已處置才算已處置。|
|R-004|日期範圍與完整計數|AC-004|Given 起迄日，When 查詢，Then 含兩端完整日期，預設台灣今日往前30日；反向／超過既有93日差上限拒絕，超過1000點仍完整納入。|
|R-005|沿用圖表規則與排除|AC-005|Given 管制規則、主副圖與排除點，When 查詢，Then 主副圖同一位置合併為一案、排除點不納入；無資料為0，讀取失敗顯示錯誤而非0。|

## 計數單位與限制
每個互動管制圖主圖位置為一件，子組圖的一組為一件，I-MR副圖異常歸入對應主圖位置。沒有主圖（純趨勢）時按原始量測點計。期間按既有量測日期篩選，不以處置日限制；顯示目前處置狀態。查詢只讀，不補建告警或重算落庫。已恢復正常而不再觸發圖表規則的歷史告警不另加入當期圖表異常件數。有資料但引擎無可用圖表的項目顯示未分析警示，不默認其為正常；整體讀取失敗則顯示錯誤。

## 測試矩陣
Happy：雙類重疊、不同項目；Boundary：零資料、無量測母體、1001筆、兩端日期；Invalid：反向及過長日期、API失敗；Regression：舊圖表1000筆、排除、I-MR／子組／計數型、無告警未處置及手機版。
