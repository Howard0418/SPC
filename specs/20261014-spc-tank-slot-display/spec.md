## Requirement

使用者回報管制圖監控明細與 SPC 管制項目總覽都應顯示「槽位」資料；系統不應在此畫面使用「槽體」作為欄位名稱。總表曾將 `蝕刻(鎳)` 顯示成 `蝕刻`，與明細卡的槽位資料不一致。

## Scope

- 調整 SPC 管制項目總覽前端顯示邏輯，保留槽位完整名稱。
- 調整管制圖監控明細文案，將「槽體」統一顯示為「槽位」。
- 不修改資料庫 schema。
- 不修改後端 API 契約。
- 不調整主檔名稱或既有資料。

## Acceptance Criteria

- AC-001：當總表 API 回傳 `slotName = 蝕刻(鎳)` 時，總表「槽位」欄完整顯示 `蝕刻(鎳)`。
- AC-002：管制圖監控明細標籤顯示「槽位」，且與總表顯示同一位置名稱時，不得一邊保留括號、一邊切掉括號後內容。
- AC-003：原本空白槽位仍顯示 `N/A`。

## Verification

- Playwright：`spc-summary.spec.ts` 加入完整槽位名稱回歸檢查。
- Frontend build：需通過，既有 chunk size warning 可接受。
