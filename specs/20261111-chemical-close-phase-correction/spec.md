# 功能規格：藥液收線舊班別修正

- 功能 ID：`SPC-CHEM-CLOSE-PHASE-1111-TASK-001`
- 版本：1
- 狀態：執行中
- 主系統：SPC API／Web、測試與正式資料庫
- 相依系統：TransFiles 藥液來源規則
- 授權：使用者於 2026-11-11 明確要求調整測試與正式資料，不可再看到晚班資料。

## 問題與已確認基準

藥液日報來源只允許早班（一般日期檔）及中班（檔名含「中班」）；補液位、更槽及暫存檔不匯入，沒有晚班資料。既有圖表卻將歷史 `SamplingPhase=CLOSE` 對應成「晚班」。`CLOSE` 是舊資料以錯欄位保存的收線語意，不是合法班別。

2026-11-11 唯讀盤點正式 `PMR_SPC_2026`，2026-10-01～10-31 有 76 筆 CHEM 量測為 `SamplingPhase=CLOSE` 且 `SamplingStage=GENERAL`；與截圖 10/20、10/22、10/28 的「晚班」點位相符。測試庫同期間沒有此類資料。

## 範圍

- 前端：不再把 `CLOSE` 標示為晚班；合法藥液圖表班別只顯示早班／中班，收線只作 N1／N2 的取樣階段呈現。
- 資料：以原始來源檔、Receipt／Trace 或批次來源可驗證時，將舊 `CLOSE/GENERAL` 量測回填成 `OPEN|MIDDLE` 加上正確 `OPEN|CLOSE` 收線階段；無法唯一判定者隔離並列清單，絕不猜測。
- 防呆：新藥液寫入僅接受 `OPEN`、`MIDDLE` 班別；`CLOSE` 不能再寫入班別欄。

## 非範圍

- 不修改濃度值、公式、F表、規格、判定、Receipt／Trace 的計算內容。
- 不把 `CLOSE` 套用到非藥液資料；不將資料視為晚班。

## 需求與驗收

| 需求 | 規則 | 驗收 |
|---|---|---|
| R-001 | 圖表不得顯示藥液晚班。 | AC-001：`CLOSE` 不再產生「晚班」標籤。 |
| R-002 | 新寫入只接受早班或中班。 | AC-002：`CLOSE` 作為班別被拒絕；既有 OPEN/MIDDLE 回歸通過。 |
| R-003 | 歷史資料只能依可追溯證據修正。 | AC-003：每筆修正均有來源、前後值與可回復清單；無證據者不改。 |
| R-004 | 測試、正式資料操作可回復且不得影響計算資料。 | AC-004：各環境備份驗證、交易、重跑冪等、公式／F／濃度值指紋保持。 |
| R-005 | 正式站需另經實際發布及連線驗證。 | AC-005：測試先行；正式僅在備份、核對與發布檢查通過後執行。 |
