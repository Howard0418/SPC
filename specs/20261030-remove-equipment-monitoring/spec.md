# 小型變更：移除 SPC 設備監控入口
- 功能 ID：SPC-REMOVE-EQUIPMENT-MONITORING-20261030
- 版本：1
- 狀態：規劃／待執行
- 優先級：P2（使用者介面與功能範圍調整）
- 專案／授權依據／需求基準：使用者 2026-10-30 需求；僅限 SPC 測試站先行，正式站需另行授權。

## 問題、預期行為與範圍
使用者要求移除 SPC 的「設備監控」功能群組，包含：

- 設備即時狀態
- 設備點位總覽
- 重點點位監控

預期行為：左側導覽不再顯示設備監控群組及上述入口；直接輸入既有路由時，顯示不可用／找不到頁面，不得繼續操作設備監控畫面。製程分析、Particle Monitoring、量測趨勢分析、SPC 週月報表、主檔與其他正常功能維持不變。

本次先移除前端入口與路由可見性，不刪除後端 API、資料表、歷史資料或設備設定，以保留可回復性；若後續要完全停用 API，另立規格。

## 需求與驗收
- R-001：左側導覽不顯示「設備監控」群組。
- R-002：設備即時狀態、設備點位總覽、重點點位監控三個入口不再可由導覽開啟。
- R-003：直接開啟三個既有路由時，顯示標準 Not Found／功能停用頁，不洩漏設備資料。
- AC-001：Given 登入 SPC，When 查看左側導覽，Then 不存在設備監控群組與三個入口。
- AC-002：Given 直接輸入三個既有路由，When 載入頁面，Then 顯示不可用提示或導向安全首頁，HTTP/API 不產生設備資料查詢。
- AC-003：製程分析、趨勢分析、週月報表、主檔維護與其他既有頁面可正常開啟；既有相關測試不回歸。
