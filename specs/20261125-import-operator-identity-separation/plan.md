# 量測匯入與登入主檔分離計畫
- 功能 ID：SPC-OPERATORS-IMPORT-IDENTITY-1125
- 規格：[spec.md](spec.md)

## 系統與實作

SPC API 的 UploadService 統一負責計量型、計數型與受控日報的確認。既有量測模型將作業人員以文字保存。確認過程移除多餘的主檔查找與建立，名稱、空值、匯入判定、覆寫及重送契約保持。角色、頁面權限、主檔及 SSO 使用原有受授權流程。核對清單與來源相依後，移除匯入專用且已無呼叫者的工廠及原行為測試。無新 API、schema、設定或資料遷移。

## 測試、部署與回復

先以 SQLite 測試實際 UploadService 預覽與確認，含兩類量測、未登記文字、已隱藏工號、同名、空白、重送及原有身份權限。回歸 SSO、稽核、一般藥液隔離與 Portal 藥液專用流程。SPC 測試站從已部署 Web 0.1.189／API 0.1.173 升為 Web 0.1.191／API 0.1.175；正式版號與測試候選區分。備份測試 Web／API，保留 IIS 設定；核對同源與 8901 直連、資產 MIME 與 API 環境。若失敗，回復測試應用與入口並驗證原版本。正式發布及指定帳號另行核准。
