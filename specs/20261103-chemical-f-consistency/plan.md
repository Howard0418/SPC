# 實作計畫

1. 核心先建立紅燈測試：複驗係數、無效階段、缺 F 與零值；Portal 一般預覽缺參數拒絕與合法公式回歸。
2. SPC Calculate／日期預覽／Portal 確認增加可選 Phase；JSON 增加 recheckConcentrationFormula。Portal 使用既有版本化代理，TransFiles 複驗傳 Recheck。管理編輯保留新增欄位。
3. 以來源活頁簿產生可追溯的測試主檔計畫；線別／槽位／項目／單位唯一匹配才處理。只更新濃度相關欄位，新增版本／日期排程，沿用匹配的不可變 F 歷史。沒有完整相符快照時，只追加來源 Excel 的不可變歷史快照（不連到啟用版本，不改全域 F）；保留其他設定及既有排程，存在衝突則不覆蓋。已確認 107 個來源公式項目對應 87 個唯一啟用業務 PPC。
4. 核心、Portal、轉檔相關測試與編譯；全部來源候選公式及數值矩陣比較。測試站獨立交付避免夾帶工作區修改；Portal 遵循 publish-all.ps1。
5. 實站連線／預覽驗收、需求及工作池／原進度 Excel 原生甘特同步、限定檔案提交上傳。

收尾風險補強：舊EXE不傳Phase，SQL直寫程序原本不能區別錯用初驗的複驗憑證。因此本件API在辨識TransFilesChemical-v1來源鍵時，preview／prepare皆強制明確Initial/Recheck；新版來源兩階段都傳，舊EXE明示需更新而非靜默算錯。不改DDL或程序，不啟用正式防護；一般舊呼叫仍預設Initial。

預檢分流：N1 催化 P400、N2 催化 P400／氯化亞錫及促進氯化亞錫，共4個主檔的另兩式含未定義 U13/U14/U16；原 Excel 此三儲存格是文字 NA。保留兩式原文；可更正濃度配置，但不啟用日期排程，不猜數字上限或不適用規則。其餘83個啟用日期政策，舊無憑證匯入會拒絕，Portal／轉檔必須使用相同日期、階段及快照。發布前完整試算預檢，四項保留待辦。

回復：測試產品回復本次備份；測試主檔以備份及預期版本檢查回復，保留追加歷史、不刪追溯。無正式 DB、全域 F 切換、migration、量測重算或排程啟用。
