# SPC-CHEM-MISSING-ADJUST-1122 補齊藥液調整兩式

SPC 測試庫的目前公式設定。來源為使用者指定的藥液分析日報表與既有對帳矩陣。前批具名參數轉換以網站既有公式為輸入，空白欄位另行補正。只補來源明確而目前空白的調整／調整量，沿用現有三參數與公式版本稽核。歷史排程、F、量測及正式環境保持原狀。

- Given Excel 公式存在且網站欄位空白、所用參數齊全，When 完成備份驗證後套用，Then 只更新缺漏欄位，新增公式版本與稽核，頁面載入後顯示公式。
- Given 網站已有公式、來源無公式或候選缺少必要參數，When 預檢，Then 不覆寫且列出原因。
- Given 目前設定與預檢基準不同，When 嘗試套用，Then 停止並重做對帳。相同清單重送應為 NoChange。
- 回復採已驗證的測試備份及該筆前版公式，依此次範圍回復目前設定。純資料補正不涉及網站發布。
