# TASK-001 設定與密鑰安全

## 目標

避免 SMTP 密碼、JWT 金鑰及資料庫密碼透過範例設定或 API 回傳外洩，並保留既有設定頁的更新流程。

## 範圍

- SMTP 設定 GET 不回傳密碼，只回傳是否已設定。
- SMTP 更新在密碼留白時保留既有密碼，避免讀取後儲存造成清空。
- 範例設定檔不得包含可用密鑰；實際密鑰改由部署環境注入。
- 不自動輪替現有測試站或正式環境密鑰，輪替由發布前作業執行。

## 驗收條件

1. API JSON 不含 SMTP 密碼值。
2. 密碼留白更新不會覆蓋既有密碼。
3. 範例設定檔的敏感欄位為空值或明確 placeholder。
4. 相關單元測試與前端建置通過。
