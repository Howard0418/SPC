# 功能規格：藥液儲存前自動更新預覽憑證

- 功能 ID：`PORTAL-CHEM-SAVE-FRESH-PREVIEW-1113-TASK-001`
- 版本：2
- 狀態：測試站完成／待登入實際儲存驗收
- 涉及專案：Portal（主系統）＋SPC（既有預覽／確認契約，不修改）
- 授權依據：使用者回報按下儲存即出現「初驗資料或日期已變更／預覽已過期」並要求可正常儲存
- 現行需求基準：[藥液量測項目精度](../20261113-chemical-entry-per-item-precision/spec.md)、[空白第二滴定值預覽一致](../20261113-chemical-preview-empty-secondary/spec.md)
- 前案：[N2促進氯化亞錫三位精度修正](../20261113-n2-promoter-tin-precision-correction/spec.md)

## 目的、現況與證據

Portal目前在輸入時取得SPC預覽憑證，確認儲存時直接重用。公式排程更新、憑證逾期，或輸入計算與點擊確認時間接近時，`ChemicalEffectiveTrace.attach`在送出API前因找不到有效token而拒絕，使用者只能看到重新計算訊息。

本次在確認儲存的最後一步，對本次變更中的日期公式列自動重新呼叫SPC preview，以同一份新結果及token立即confirm；直接輸入項目不新增preview，SPC仍保留輸入／日期／規格／排程變更的409防護。

## 範圍與非範圍

- 修改Portal量測錄入頁與共用預覽追蹤JS；不修改SPC公式、F、排程、資料庫、schema或既有量測。
- 只重新預覽本次實際送出的日期公式列；初驗及有填複驗原始值的複驗皆更新。
- 自動預覽回傳的分析值、調整與調整量成為同批確認內容，避免新token搭配舊結果。
- 不放寬SPC確認驗證；preview或confirm失敗時保留畫面輸入並顯示錯誤。

## 需求與驗收

| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|
| R-001 | 日期公式列儲存前必須使用最新預覽 | AC-001 | 已有舊token時按確認，Portal再preview一次，confirm使用第二次token及結果 |
| R-002 | 初驗／複驗需同批一致 | AC-002 | 有複驗原始滴定值時兩階段皆刷新；沒有複驗時只刷新初驗 |
| R-003 | 失敗不得清除輸入或繞過SPC | AC-003 | preview／confirm失敗保留草稿；SPC 409仍顯示且不建立成功狀態 |
| R-004 | 非日期公式不增加副作用 | AC-004 | 直接輸入列保持原流程，不呼叫日期公式preview |

## BDD

- Given 使用者已輸入滴定值且舊預覽因排程更新失效，When 按下確認儲存，Then Portal自動取得新預覽並以新token成功確認，不要求手動重算。
- Given 新預覽或確認失敗，When 儲存流程結束，Then 原輸入仍留在畫面且顯示可理解錯誤。

## 例外與邊界

- 日期公式列缺初驗原始滴定值時仍拒絕，不以分析值反推。
- 複驗分析值存在但沒有複驗原始滴定值時仍拒絕。
- preview與confirm之間再次發生排程變更時，沿用SPC 409拒絕，不重試寫入。

## 假設與未決問題

無阻擋未決問題；本次僅改善儲存前預覽協調，不改計算規則。
