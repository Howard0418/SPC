# 計畫

1. 建立來源掃描器：解析日期／班別，排除補液位、更槽及暫存檔，輸出逐檔 SHA 與排除原因。
2. 建立標題導向解析器：核對 Sheet／表內線別、N1／N2 開收線、初複驗滴定與濃度；欄位移位不硬抓。
3. 先寫自動化測試：Happy Path、日期邊界、`-`直接濃度、0值、缺公式／F、欄位移位、重複與同鍵衝突。
4. 產生只讀 preview 與「待修正 Excel」：候選、略過、排除、錯誤及防重衝突分表；人工核對各檔／Sheet筆數。
5. 使用者確認 preview 後才備份並寫入測試 DB；重送相同 manifest 驗證新增 0，正式 DB 前後唯讀指紋保持。
6. 以網站實際查詢驗收日期、班別、線別、開收線、初複驗、公式／F／直接濃度及來源追溯；錯誤可快速篩選。
7. 完成驗證、rollback 演練與文件同步後才標記測試完成；正式區維持未執行並另待授權。

## 建議來源格式

- 早班檔名統一 `yyyy-MM-dd.xlsx`，中班統一 `yyyy-MM-dd中班.xlsx`。
- 排除檔仍在檔名保留「補液位」或「更槽」，避免被誤認一般日報；關閉 Excel 後再掃描，避免 `~$` 暫存檔。
- Sheet 建議使用 `N1（開）`、`N1（收）`、`N2（開）`、`N2（收）`；其他線別直接使用線別代碼。
- 直接濃度列：滴定數填 `-`，濃度填數字；公式列：滴定數、日期適用公式與 F 必須完整，Excel 濃度保留供核對。
- 未量測列的滴定與濃度都保持空白或一致的 `-`；不要填 0 表示未量測。
- 檔內日期及線別須與檔名／Sheet一致；不一致將隔離，不由工具猜測。

## 已確認規則

- 早班顯示時間採 `08:00`、中班採 `16:00`，皆標示為報表班別時間而非實際取樣時間；使用者已於2026-11-05確認。
- 同日同班多份合格檔若發生衝突，必須由核准清單指定修正版，不沿用舊的「後檔自動取代前檔」。
