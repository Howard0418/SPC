# SPC-CHEM-OVERVIEW-FOLLOW-1123 兩項正式公式收尾

使用者確認 PPC 2518 調整公式先改為未設定，PPC 2594 延續既有 20 g/L 稀釋門檻並同步已驗收的調整量公式。

- Given 正式 PPC 2518 對應測試區刻意留白，When 執行本次授權，Then 單獨清除該項調整公式。
- Given PPC 2594 的原高值分支採大於 20 g/L、添加值已設定，When 套用測試調整量公式，Then 設定稀釋管制值為 20，既有調整判斷保持，20 g/L 無稀釋，高於 20 g/L 的排藥量與補水量皆以 20 為基準。
