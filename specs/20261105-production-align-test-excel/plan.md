# 計畫

1. 核對轉檔工具來源路徑、實際檔案存取與已封存manifest，建立完整列帳。
2. 固定兩區業務快照，排除測試fixture，真Excel來源以原業務鍵比對；對齊主檔／資料候選先通過來源與既有規則驗證。
3. 核心planner先測試，正式環境／備份後分批受控套用，可獨立安全完成的主檔差異先處理；來源衝突保留。
4. 每批後重送、來源查回與保護指紋；不因程式版本不同擅自發布API。
5. 產出Excel來源逐檔、差異與待修正清單；同步工作池與原進度表並提交必要程式文件。

使用者後續授權2026全年，缺實際時間藥液仍待補。咬蝕工具只有明示`--year=2026`才擴大原九／十月預設，固定2026及截至2026-11-05；拒絕空集合、跨年、未來日期、同日線別重複。環境／來源SHA／備份／原資料指紋及完整25／50樣本規則保持，X及無效值不匯入。
