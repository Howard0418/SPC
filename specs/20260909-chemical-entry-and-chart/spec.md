# 功能規格：藥液中班、當日刪除與圖表規格線
- 功能 ID：20260909-chemical-entry-and-chart
- 版本：1
- 狀態：實作中
- 涉及專案：SPC、PmrPortal
- 授權依據：2026-09-09 使用者需求；僅測試環境驗證與發布，正式環境暫不發布。
- 現行需求基準：[SPC 現行需求基準](../../docs/SPC_REQUIREMENTS_BASELINE_2026-08-07.md) 第 7 節。
- 前案或相關規格：2026-09-02 N1／N2 藥液日報開收線分開錄入、2026-09-02 藥液日報開收線成對管制圖。

## 目的、現況與證據
- 已確認需求：任一分析項目的管制圖均須可見已設定的上下規格界線；藥液錄入須可選早班與中班；可刪除當天已輸入的一筆藥液資料再重輸。
- 程式觀察：`SpcChartView.vue` 已建立 USL／LSL 標記線，但一般管制圖 y 軸使用 ECharts 自動縮放，未明確納入規格與管制界線，超出量測範圍的界線可能被裁切。
- 程式觀察：Portal 日報以 `SamplingPhase` 區分 N1／N2 的 `OPEN`、`CLOSE`；SPC 每日唯一索引也包含該欄位。現有正規化未接受中班值。
- 程式觀察：歷史查詢回傳單筆量測 ID，但現有 Portal 及 SPC API 沒有日報單筆刪除路徑。

## 範圍與非範圍
範圍：
- SPC 管制圖與趨勢圖的 y 軸範圍納入有效量測、USL、LSL、Target 與顯示中的管制界線，保留合理邊距。
- N1／N2 藥液日報新增 `MIDDLE` 中班，與早班 `OPEN`、晚班 `CLOSE` 同日獨立保存與載入。
- Portal 歷史查詢增加逐筆刪除；只允許刪除 Portal 日報來源的當日資料，並清除該筆衍生 SPC 計算及關聯警示。
- 藥液日報新增、修改、刪除均保留稽核明細，包含動作、操作者、時間、量測 ID 及前後值；Portal 查詢與寫入代理僅限品保角色。
- Portal 與 SPC 建置、測試環境發布與 HTTP 驗證。

非範圍：
- 不修改正式環境、既有 Excel／TransFiles 匯入或非 Portal 日報量測。
- 不重新命名既有開線／收線資料與不批次搬移歷史資料。
- 不變更規格或管制界線數值及計算公式。

## 需求與驗收
| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|
| R-001 | 圖表顯示已設定規格時，視窗範圍必須涵蓋 USL 與 LSL，不得因刻度裁切。 | AC-001 | 量測與控制界線皆在 USL／LSL 內側或外側時，產生的 y 軸最小/最大值仍分別小於 LSL、大於 USL。 |
| R-002 | 所有線別藥液錄入提供早班與中班；中班以 `MIDDLE` 獨立保存與查詢，晚班暫不在畫面提供。 | AC-002 | 同一機台、日期、管制項目可各儲存與讀回 `OPEN`、`MIDDLE`，互不覆寫；畫面不可選取晚班。 |
| R-003 | 品保人員可從歷史查詢刪除一筆當日 Portal 日報資料，刪除後可重新輸入。 | AC-003 | 刪除按鈕完成確認後資料從列表消失，SPC 的量測、計算及該筆警示均移除；非 Portal 日報來源遭 API 拒絕。 |
| R-004 | 新增、修改、刪除藥液量測均須保留稽核記錄，所有 Portal 操作僅限品保角色。 | AC-004 | `UploadDetails` 有 `ManualMeasurementCreated`、`ManualMeasurementUpdated`、`ManualMeasurementDeleted`，含操作者、時間與前後值；非品保請求遭 Portal API 授權拒絕。 |

## 例外與邊界
- 規格或管制界線為空、非有限數值時不應影響其他有效數值的軸範圍。
- 沒有足夠範圍時採用最小邊距，避免 y 軸上下界相同。
- 所有線別均顯示早班／中班下拉並送出 `OPEN`／`MIDDLE`；晚班 `CLOSE` 暫不顯示於 Portal 畫面，後端仍保留既有資料相容性。既有 `GENERAL` 資料仍保留，不因本次畫面修改刪除。
- 刪除 API 必須在交易中處理量測、計算與警示；找不到資料回傳 404，非 Portal 日報資料回傳 409。

## 假設與未決問題
無阻擋問題。畫面班別名稱採「早班／中班」，分別對應既有 `OPEN`、新增 `MIDDLE`；晚班 `CLOSE` 僅保留後端相容性，待未來需求確認後再恢復畫面選項。

## 明確邊界與假設
「當天」按台北日期判定日報業務日期，無日報日期則按量測時間換算；不提供歷史日刪除。
刪除沿用既有品保入口與 SPC 寫入權限，不新增對 Viewer 的刪除權限。
規格不存在時明示未設定，不為所有項目自動補規格。匯入檔未帶班別沿用早班，本次不修改 TransFiles。
不重算不相關量測，不改既有能力指標公式/標籤或 SSO。
