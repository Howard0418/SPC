## 目的、現況與證據

指定活頁簿共有 12 張工作表，其中 CN、N1（開）、N1（收）、N2（開）、N2（收）、C1、C3、C5、DP、舊線、新線共 11 張為藥液資料表，合計 142 個分析列；F 工作表是係數來源，不是槽容／管制值主表。唯讀盤點詳見 [來源盤點](source-inventory.md)。

現行 `ChemicalAnalysisConfigJson` 已可同時保存調整／調整量公式與 `tankCapacityLiters`、`additionControlValue`、`dilutionControlValue`。但目前有三個缺口：

1. 「藥液量測調整公式」頁只維護三個參數，不顯示兩式；「線別分析項目總覽」只顯示兩式，不顯示三個參數，人工無法在同列交叉確認。
2. 現行計算器只提供 `Primary`、`Secondary`、`LSL`、`USL`、`Target`、`Concentration` 與 F 儲存格給公式使用，尚未把三個調整參數提供為公式變數。
3. Excel 並非所有調整量公式都以管制值當作目標值；部分另含配槽目標、藥液倍率或固定槽容。因此不能把公式內所有常數直接改成添加／稀釋管制值。

## 權責與資料契約

- 指定 Excel 是本次核對基準及轉換證據，不作網站執行時依賴，也不由網站直接讀取桌面檔案。
- 「藥液量測調整公式」頁是槽容、添加管制值、稀釋管制值的唯一編輯入口。
- 「線別分析項目總覽」維持調整／調整量公式的編輯入口，並唯讀顯示同一份三參數及對帳狀態，避免兩個頁面可同時修改同一欄位。
- 三參數與兩式仍保存於同一 PPC 的 `ChemicalAnalysisConfigJson`，沿用既有公式版本與稽核，不建立第二份主檔。
- 實際計算使用有效排程所選、不可變公式版本內的三參數；目前 PPC 尚未排程的參數異動不得回寫或改變既有排程與歷史試算。
- 公式新增下列不分大小寫的具名變數：`TANK_CAPACITY_LITERS`、`ADDITION_CONTROL_VALUE`、`DILUTION_CONTROL_VALUE`。未設定卻被公式引用時須明確拒絕計算，不得以 0 代入。
- Excel A1 儲存格參照不得原樣存入網站；須先轉為網站公式語言與具名變數，再以固定案例驗算。

## 範圍與非範圍

### 範圍

- 建立 Excel 每列與網站 PPC 的自然鍵對照矩陣：工作表／線別、槽別、分析項目、開收線階段、有效日期或 ECR 證據。
- 比對槽容、添加管制值、稀釋管制值、調整公式及調整量公式，分類為相符、僅格式差異、網站缺值、Excel 缺值、公式語意差異、無法唯一配對。
- 讓計算器可安全引用三個具名參數，並建立 Happy Path、Boundary、Invalid Input、Regression 自動化測試。
- 線別分析項目總覽同列顯示三參數、兩式及對帳狀態，Excel 匯出同步包含三參數。
- 經核准的矩陣只先套用測試資料，完成前後快照、版本、稽核、計算及畫面驗收。

### 非範圍

- 本規劃階段不修改來源 Excel、程式、資料庫、公式、網站資料或站台。
- 不以空白、`NA`、`N/A` 或 `-` 覆寫網站既有有效值。
- 不修改濃度公式、F 表、規格上下限、歷史量測或正式資料。
- 正式資料與正式站發布須另行明確授權。

## BDD 行為

### Scenario：相符列可安全形成候選變更

Given Excel 某列可唯一對應一個啟用中的藥液 PPC，且槽容與兩個管制值皆為正數；
When 執行唯讀對帳；
Then 報告同列顯示 Excel 值、網站值與差異分類，且不寫入資料庫。

### Scenario：NA 與空白不覆寫

Given Excel 的添加或稀釋管制值為 `NA` 或空白，而網站已有有效值；
When 產生套用預覽；
Then 該欄標示「待業務確認／不覆寫」，不得轉成 0、空字串或 null 自動提交。

### Scenario：門檻與調整量目標分離

Given Excel 的添加門檻為 2.5，但調整量公式另以 3 作配槽目標；
When 轉換公式；
Then 2.5 對應 `ADDITION_CONTROL_VALUE`，3 保留為獨立目標常數並在報告揭露，不得用 2.5 取代 3。

### Scenario：公式引用缺少的參數

Given 調整量公式引用 `TANK_CAPACITY_LITERS`，但該 PPC 槽容未設定；
When 執行計算；
Then API 回傳可辨識的缺少參數錯誤，且不保存錯誤調整量。

### Scenario：兩頁同源顯示

Given 某 PPC 已設定三參數與兩式；
When 分別開啟調整參數頁與線別分析項目總覽；
Then 兩頁三參數相同，總覽同列顯示兩式與三參數，且三參數不可在總覽編輯。

### Scenario：未確認差異零寫入

Given 對帳列存在重複自然鍵、開／收線不同值、Excel 缺公式或硬編碼槽容；
When 執行測試資料套用；
Then 該列被隔離，其他已核准列可提交，隔離列的網站設定與版本數不變。

## 例外與邊界

- C3、C5、DP 的標題是「槽容」而非「槽容(L)」，視為同一來源欄位，但輸出統一以 L 顯示。
- N1／N2 開、收線若同一 PPC 值相同可合併為一筆候選；若不同，不自行選擇勝者。
- 來源有 15 列槽容空白、25 個添加 `NA`、41 個稀釋 `NA`、3 列缺調整公式、39 列缺調整量公式，均須在矩陣保留原狀與原因。
- 缺調整量公式不一定是錯誤；若業務動作只有通知、換槽或無定量添加，可確認為合法未設定。
- 公式中的固定數字可能是目標濃度、比重、藥液倍率、有效濃度或局部槽容，只有具證據者才轉為參數。
- 來源檔目前由其他程序開啟；正式對帳基線須在使用者儲存並關閉後重新計算檔案雜湊，避免讀到未保存版本。

## 假設與未決問題

- 建議採用「調整參數頁唯一編輯、總覽唯讀顯示」；若使用者希望兩頁都可編輯，須另增併發與覆寫防護，不在本版預設。
- `NA` 預設解讀為該方向不適用，但因現有部分 Excel 公式仍參照 `NA` 儲存格，須在 T-001 逐列確認為單向規則、換槽規則或來源錯誤後，才可轉換網站公式。
- 調整量公式中的獨立目標值是否也要建立專用參數欄位，待 T-001 語意分類後決定；在此之前保留為公式常數並揭露。
