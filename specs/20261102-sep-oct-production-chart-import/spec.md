# 功能規格：9、10 月資料受控匯入與圖表驗證

- 功能 ID：SPC-HISTORICAL-IMPORT-1102
- 版本：1
- 狀態：僅規劃／待選擇小工作
- 涉及專案：SPC；來源可能由 TransFiles 提供，正式寫入只限 SPC 正式資料庫
- 授權依據：2026-11-02 使用者要求「9月、10月資料匯入測試，正式資料庫，確認可以正常的繪製管制圖跟趨勢圖」，並明確要求先規劃、加入小工作、不立即執行。
- 現行需求基準：[需求索引](../../docs/requirements.md)
- 相關前案：[2026-09 咬蝕正式匯入](../20260922-etch-production-import/spec.md)、[FORMULA-IMPORT-005](../20261101-formula-import-test-source-regression/spec.md)。

## 目的、現況與證據

既有 2026-09 咬蝕正式匯入已完成，但其來源、48 份 manifest、資料類別和圖表驗收範圍不能直接視為本次「9、10 月資料」的完整集合。本次尚未指定來源目錄、檔名、資料類型（咬蝕／藥液／粒子或其他）、每月涵蓋日數、及要驗收的 PPC／線別。

因此先建立可追溯、可停止、不可覆寫的工作拆分；不讀寫正式資料庫、不執行匯入、不發布網站。本次輸入若格式不符，必須在唯讀預覽列出檔案、工作表、列／欄、原值、預期格式與建議，不得猜測或補零。

## 範圍與非範圍

範圍：2026 年 9 月與 10 月原始資料的來源鎖定、唯讀解析、測試環境預覽／受控匯入、正式環境 preflight、經另行正式授權後的僅新增匯入、及管制圖／趨勢圖逐組驗收。

非範圍：不覆寫或刪除既有正式資料；不複製測試資料列到正式庫；不修改原始 Excel、主檔、公式、規格、管制界限、排程、Portal、權限或正式網站；不將本次規劃視為正式寫入授權。若預覽發現主檔缺漏或規格不一致，停止並另列差異，不自動補建。

## 例外與邊界

- 日期、線別、PPC、單位、階段、子組樣本數、必填欄或數值格式缺失／不符：只列格式報告與調整建議，不寫入。
- 空值與 0 必須區分；0 為有效量測值時不可當成缺值。重複來源鍵、同鍵不同值、跨月、跨日、負值、受保護公式欄均須獨立呈現。
- 一份資料可驗證多組圖表；至少每月各一組，實際組數依來源／PPC 分布及 preflight manifest 固定，不能以空圖或單一 API 取代兩種圖表。
- 截圖只於實作驗收時取得，應遮蔽帳號／權杖等機敏內容；本次規劃不產生假截圖。

- 正式目標預期為 `PMR_SPC_2026`，但每次 preflight 仍須從實際正式環境核對；本次未取得正式寫入授權。
- 管制圖／趨勢圖的指定 PPC／線別尚未指定；TASK-001 依實際來源提出候選清單，TASK-003 固定驗收矩陣後才可執行正式 apply。
