# 兩組同名人員主檔整理計畫
- 功能 ID：SPC-OPERATORS-FOLLOWUP-1125

1. 核對匯入防重正式 API、正式備份及既有軟退役流程。分組以正式 Portal AD／工號、歷史資料型態與引用預檢。執行程式先在合成資料演練。
2. 每組獨立交易。在登入身分鎖內再次核對兩筆身份及校正、報表、通知、授權與稽核引用。保留前影像，停用及隱藏歷史列並清除登入值，與安全稽核同一交易。
3. 另開連線查回及核對一筆有效 AD、舊列及稽核事件。核對管理頁的清單內容。瀏覽器無法刷新時以實際清單控制器連接正式資料進行唯讀驗證。共用範圍內保留正式登入帳號與權限。
4. 回復限該組三個異動欄位，先比對目前影像及已提交稽核。正式資料庫備份驗證、分組回復與證據留正式受控目錄。

本次為正式個案資料維護，網站發布、schema 與版本遞增不適用。
