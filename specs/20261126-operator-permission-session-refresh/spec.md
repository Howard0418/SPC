# 功能規格：作業人員權限免登出更新
- 功能 ID：SPC-OPERATOR-PERMISSION-SESSION-REFRESH-1126
- 版本：1
- 狀態：完成，已發布測試站
- 涉及專案：SPC API、SPC Web
- 授權依據：使用者於 2026-11-26 確認，權限儲存後可直接更新，不必登出再登入。
- 現行需求基準：[需求索引](../../docs/requirements.md)
- 前案或相關規格：[作業人員頁面權限總覽](../20261120-operator-page-permission-overview/spec.md)、[安全稽核](../20261120-audit-business-action-allowlist/verification.md)

## 目的、現況與證據

- 現況：登入時 API 將角色與頁面權限寫入 JWT，Web 另將使用者與權限保存在 `mes_spc_user`。作業人員頁儲存只更新資料庫及清單列，既有登入階段仍使用舊 JWT 與本機權限。
- 目的：本人權限儲存後立即同步，其他已登入使用者於下一次站內切頁或重新整理時同步資料庫最新權限。原登入憑證保留到期時間。
- 安全基準：稽核權限仍須由安全管理者明示授予，且不可替自己加權；本功能不得繞過既有 `SecurityAuditFilter`。

## 範圍與非範圍

- 範圍：新增受 JWT 保護的登入階段刷新 API；Web 路由切換同步登入階段；作業人員儲存本人資料後立即同步；選單與路由權限改用刷新結果。
- 非範圍：不新增角色、不修改權限目錄、不調整資料庫 schema、不以 WebSocket 強制推播其他裝置、不放寬安全稽核或正式發布授權。

| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|

## 例外與邊界

- refresh 暫時網路失敗或 API 滾動更新期間無此端點時，切頁可暫用現有快取，業務 API 原有驗證仍有效；不得清除使用者未送出的表單。
- 同步成功後若目前頁面已失去權限，導向第一個可用頁面。完全無可用頁面時顯示權限提示，取得授權後可重新整理。
- 作業人員儲存不是本人時，不可把被編輯者的登入身分寫入管理者瀏覽器。
- 既有 JWT 的有效期保持。其他使用者以切頁或重新整理更新選單，原本已有權限控管的 API 則從下次請求使用最新狀態。
