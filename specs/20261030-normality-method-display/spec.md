# 小型變更：SPC 即時互動管制圖顯示常態檢定方法
- 功能 ID：SPC-NORMALITY-DISPLAY-20261030
- 版本：1
- 狀態：規劃／待執行
- 專案／授權依據／需求基準：使用者 2026-10-30 需求；沿用 `specs/20261014-normality-method-switch/spec.md` 與現行 Anderson-Darling 設定。

## 問題、預期行為與範圍
「SPC 即時互動管制圖」目前常態檢定方法未顯示，使用者無法確認圖表採用的檢定方法。應在既有查詢區或常態分析結果區清楚顯示目前方法（現行為 Anderson-Darling），只補充顯示，不改變計算、API、資料庫、權限或其他圖表功能。

範圍限定：SPC Web 即時互動管制圖頁面；不處理量測趨勢圖、後端演算法、正式站發布或其他頁面。

## 需求與驗收
- R-001：即時互動管制圖頁面顯示目前常態檢定方法，文字至少包含「常態檢定方法」及實際方法名稱。
- R-002：顯示值與查詢所使用的 `normalityMethod`／API 回應一致；缺少方法資訊時顯示可讀的「未提供」狀態，不顯示錯誤或空白誤導文字。
- AC-001：Given 開啟即時互動管制圖並完成查詢，When 查看常態分析區，Then 可看見 `常態檢定方法：Anderson-Darling`（或 API 實際回傳的方法）。
- AC-002：Given API 回應缺少常態方法欄位，When 顯示結果，Then 頁面維持其他圖表與資料正常，方法欄顯示「未提供」或等效提示。
- AC-003：不影響既有管制線、常態檢定數值、直方圖、查詢與匯出功能；現有相關測試須維持通過。
