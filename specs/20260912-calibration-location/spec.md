# 功能規格：儀器主檔顯示放置地點
- 功能 ID：20260912-calibration-location
- 版本：1
- 狀態：可實作
- 涉及專案：SPC
- 授權依據：2026-09-12 使用者「秀出放置地點」
- 現行需求基準：[需求索引](../../docs/requirements.md)、[基準 3.6](../../docs/SPC_REQUIREMENTS_BASELINE_2026-08-07.md)
- 前案：[儀器校正](../20260911-instrument-calibration/spec.md)、[Excel 匯入](../20260911-instrument-calibration-import/spec.md)

## 目的、現況與證據
Excel 第一工作表 H5 為「放置地點」，59 筆均有值。現行主檔與畫面只有部門，匯入明確不拿放置地點推定部門，因此列表看不到實際放置處。

## 範圍與非範圍
範圍：主檔可選欄位、列表／表單／匯入預覽顯示、Excel H 欄讀取與寫入。非範圍：不推定部門、不改通知規則、不改量測、不寫正式庫以外之測試站 migration 授權另依發布。

## 需求與驗收
| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|
| R-001 | 主檔新增可選「放置地點」，最多 100 字；空白為空。 | AC-001 | 新增／編輯可填可清空；超長拒絕。 |
| R-002 | 列表與表單顯示放置地點。 | AC-002 | 儀器校正管理表格有「放置地點」欄。 |
| R-003 | 匯入讀 H 欄；H5 須為放置地點；不推定部門。 | AC-003 | 預覽與提交保留 H 值；部門仍僅來自使用者指定。 |

## 例外與邊界
空白可匯入。公式儲存格比照名稱，需先轉成值。不覆寫既有編號的放置地點。

## 假設與未決問題
無阻擋問題。既有儀器無此欄時畫面顯示空白。
