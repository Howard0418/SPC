# 藥液日報最近規格版本判定

## 需求
- 既有量測有保存規格／追溯時，沿用該保存證據。
- 保存追溯存在但無效、缺漏或沒有判定時，不得停在無法判定；繼續套用最近版本／目前 PPC 範圍。
- 量測日沒有對應保存規格時，從同一 PPC 的規格版本選擇日期距離量測日最近者，以該版本 LSL／USL 判定。
- 同一 PPC 完全沒有規格版本歷史時，以該 PPC 目前設定的 LSL／USL 作最後回退判定。
- 同距離時優先採量測日以前的版本，再以較高版本號決定。
- 上下限皆缺、非有限數或 LSL 大於 USL 時仍為「無法判定」，不得臆造。
- 回傳判定來源、版本號與版本日期；不修改量測、公式、F 表、規格歷史或正式站。

## BDD
- Given 11/10 量測無保存規格，且 11/09 與 11/11 有有效規格版本；When 載入日報；Then 同距離時採 11/09 過去版本及其範圍判定。
- Given 最近規格只有 LSL 或只有 USL；When 數值落在有效側；Then 以單側界限判定。
- Given 最近版本上下限無效；When 載入；Then 顯示無法判定及原因。
- Given 已有有效保存規格；When 載入；Then 保存規格仍優先，不被最近版本覆蓋。
- Given PPC 有上下限但規格版本歷史為 0；When 載入；Then 依目前 PPC 範圍判定，不再顯示無法判定。
- Given 舊量測帶有無效 Receipt／Trace，且 PPC 有有效範圍；When 載入；Then 忽略無效追溯並依範圍判定。
