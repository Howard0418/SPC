# 功能規格：日期公式匯入測試來源與回歸

- 功能 ID：FORMULA-IMPORT-005
- 狀態：測試通過／待人工驗收；2026-11-02另獲允許隔離驗算，8筆測試HTTP與Excel吻合；不將測試日期作業務生效日。
- 主系統：TransFiles
- 相依系統：SPC測試API（T3b允許登入後preview，不允許prepare／confirm／匯入DB程序；另獲允許建立獨立測試基準）。
- 授權依據：使用者於 2026-11-01 指示「繼續」。
- 現行需求基準：[日期公式 DB 匯入環境與版本歷史](../20261029-chemical-formula-db-import-environment-history/spec.md)

## 現況與問題

使用者已確認共用來源為 `\\172.16.119.200\LineData` 且可讀；轉檔工具原始碼的每日藥液、咬蝕量預設仍指向舊 `172.16.119.120`。雖然使用者可自行選取資料夾，但「每日檢查」捷徑與排程預設會因此讀到錯誤來源。

## 範圍

- 將 GUI 與排程的日報預設 UNC 基底一致改為 `\\172.16.119.200\LineData`。
- 建立來源主機一致性測試，並對實際來源進行只讀單檔解析與 dry-run 可用性核對。
- 初版不進行preview；2026-11-02後續選取T3b允許代表性測試preview。prepare、confirm、測試／正式量測寫入、工具打包或發布仍不執行。使用者後續允許[獨立測試基準](isolated-fixture-20261102.md)，僅新測試PPC排程可建立，不改業務排程。

## 實際來源核對結果與後續範圍

- `2026-10-30.xlsx` 為尚未填值的日報樣板，12 張工作表都沒有可解析資料，不能作為匯入成功證據。
- `2026-10-27.xlsx` 的 CN、N2、C1、C3、C5、舊線與新線工作表可讀到 `B4` 日期與 H／I 欄的原始／分析值；這是現行解析器未支援的矩陣式日報格式，不可把檔名當作日期替代。
- 後續 T3b 需以工作表內日期、槽位、項目、規格、原始值、Excel 公式快取結果及 F 表儲存格，解析矩陣式日報並先做唯讀 preview。未完成前不得宣稱可正式或測試寫入。
