# 功能規格：管制線計算法反映於圖表
- 功能 ID：`SPC-CONTROL-LIMIT-METHOD-1119-TASK-001`
- 版本：3
- 狀態：測試區完成／待正式授權
- 涉及專案：SPC API／Web
- 授權依據：使用者於 2026-11-19 回報選擇「樣本標準差法」後，管制圖 UCL／LCL 未改變，並要求驗證。
- 現行需求基準：[管制線公式儲存後重算重繪](../20261029-control-line-formula-recalc/spec.md)
- 前案或相關規格：`SPC-ADJUST-1028-TASK-001`、`SPC-CONTROL-CHART-AUTO-REFRESH-1111-TASK-001`

## 目的、現況與證據
後端已依 `FormulaConfigJson` 計算標準全距、平均移動全距或樣本標準差界限，但組裝圖點時會優先採用 PPC／日期區段既有 UCL、CL、LCL。前端偵測到圖點具有逐點界限後優先繪製該組資料，因此明確選擇樣本標準差法時仍可能顯示舊界限。

## 範圍與非範圍
- 範圍：Xbar-R 與 Xbar-S 明確選擇管制線計算法時，圖點與判定採用該方法本次計算出的 UCL／CL／LCL。
- 非範圍：不修改量測值、規格線 USL／Target／LSL、公式 JSON、日期區段資料、Xbar-S 演算法或正式資料。

## 需求與驗收
| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|
| R-001 | 明確選擇樣本標準差法時，Xbar 圖 UCL／CL／LCL 必須採 `XDoubleBar ± Multiplier × S_Xbar`，不得被既有主檔界限覆蓋。 | AC-001 | Given PPC 已有固定 UCL／LCL，When 以 `SIGMA_METHOD` 計算，Then 回傳圖點界限等於樣本標準差法結果且不同於固定界限。 |
| R-002 | 明確選擇平均移動全距或標準全距法時，亦須顯示各自的計算界限。 | AC-002 | 同一組非對稱樣本切換方法後，回傳的圖點 UCL／LCL依各方法改變。 |
| R-003 | 未明確設定公式時保留既有相容行為。 | AC-003 | 空白公式設定仍可沿用主檔／日期區段既有界限。 |
| R-004 | Xbar-S 亦須讀取所選管制線計算法；其下方 S 圖仍維持既有 S 管制算法。 | AC-004 | Given 同一組 Xbar-S 資料，When 由標準全距切換為樣本標準差，Then 上方 Xbar 圖 UCL／LCL 改變，下方 S 圖算法不變。 |
| R-005 | 標準全距法只能用於已有 A2／D3／D4 常數的子組大小 2～25；超出範圍不得靜默回退其他算法。 | AC-005 | Given 子組大小為 50，When 開啟公式設定，Then 不提供標準全距法並顯示原因；直接送出 `STANDARD_RANGE` 時 API 拒絕且不修改原設定。 |

## 例外與邊界
- 有效子組不足以計算所選方法時，不產生無效數字；若是標準全距法常數不支援，須在儲存前明確阻擋，不可靜默改用其他方法。
- Xbar-S 的所選方法只改上方 Xbar 管制線；下方 S 管制線仍採 B3／B4 × S̄。

## 假設與未決問題
無阻擋性問題；使用者本次問題聚焦「所選計算法未反映於圖表」。
