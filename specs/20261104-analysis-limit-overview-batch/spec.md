## 目的、現況與證據

使用者目前可在「SPC 管制項目設定」逐筆查看／編輯 `LSL、Target、USL` 與 `LCL、CL、UCL`；「線別分析項目總覽」則已有篩選、分頁、逐列編輯、dirty row標示、一次儲存、逐列結果及版本歷史的操作模式。本需求新增專用表格頁，降低逐筆進入抽屜修改的操作成本。

現行 `GET /part-process-characteristics` 已回傳六個界限欄位及線別／製程／槽位／特性關聯。現行通用 `PUT` 會更新整筆PPC，若批次頁直接回送載入時的完整物件，可能覆蓋其他使用者稍後修改的公式、啟停或圖型設定。因此本案不得直接複製公式頁的整筆PUT payload；UI可沿用其操作體驗，寫入契約須限定為界限欄位並檢查資料是否過期。

規格界限目前已有不可變版本快照，追蹤 `LSL／Target／USL`、操作者及修改時間；控制界限 `LCL／CL／UCL` 是否已有完整前後值追溯，實作前須依現行稽核契約確認。沒有可回復證據時，不得把批次頁標示為可正式使用。

本次沒有新截圖附件。後續驗收應提供不含帳密／Token的測試站截圖，包含總覽、異動列、預檢結果、儲存結果及版本／稽核紀錄。

## 範圍與非範圍

範圍：

- 新增「分析項目界限總覽」頁及導覽入口，沿用Editor權限。
- 以表格顯示範圍／製程或線別／槽位／分析項目／單位／啟用狀態，以及規格 `LSL、Target、USL`、管制 `LCL、CL、UCL`。
- 支援範圍、製程／線別、槽位、狀態及「缺規格／自動管制線／手動管制線／格式問題」篩選與5／10／20／50筆分頁。
- 逐列進入編輯、標示異動、單列還原；批次儲存涵蓋所有異動列，不受目前分頁／篩選切換影響。
- 儲存前由伺服器預檢，顯示變更前後值、格式錯誤、過期資料與受影響筆數；確認後只更新六個界限欄位。
- 規格變更沿用既有版本歷史；管制界限須保留可追溯前後值、操作者、時間及批次識別。
- 支援匯出目前篩選結果供核對；第一版不支援Excel回匯。

非範圍：

- 不改既有公式、F值、圖型類型、抽樣數、顯示模式、啟停、量測或歷史計算結果。
- 不自動把規格界限複製成管制界限，也不以規格界限取代統計計算的自動管制線。
- 不編輯生效日期分段；分段界限仍由既有分段功能維護，總覽須清楚提示目前另有分段。
- 不移除或取代既有單筆管制項目設定頁及版本歷史。
- 規劃階段未修改程式、資料庫、資料或網站；2026-11-09 依「完成所有 SPC 未完成小工作」開始實作，正式資料與正式發布仍排除。

## 欄位與格式規則

| 欄位 | 顯示／輸入規則 | 格式不符時的調整方式 |
|---|---|---|
| LSL／USL | 可單邊設定；兩者都有時必須 `LSL < USL` | 只輸入數字；移除單位、逗號、全形符號及「±」文字 |
| Target | 可空白；有上下限時必須落在範圍內 | `100 ± 20`應拆為LSL=80、Target=100、USL=120 |
| LCL／CL／UCL | 空白表示沿用自動計算；手動值依圖型現行規則驗證順序 | 不可用`自動`、`Auto`或`-`作數值；要自動計算就保持三欄空白 |
| 數字 | 接受負數、小數與0；空白與0意義不同 | 使用半形小數點，例如`0.95`；不可輸入`0,95`、`95%`或`0.95 mg/L` |
| 單位 | 只顯示，不在界限輸入格重複輸入 | 若單位錯誤，回原單筆主檔修正，批次頁不得順便改單位 |
| 自動／手動模式 | 顯示系統實際來源；不得因開啟編輯而改變 | 若需從自動改手動，須填妥該圖型必要欄位並通過預檢 |

## BDD

- Given使用者在第1頁及第3頁各修改一筆界限，When返回第1頁並儲存，Then確認清單包含兩筆且只更新兩筆。
- Given一筆PPC在載入後由另一人修改界限，When使用者送出舊草稿，Then伺服器拒絕該批並提示重新載入，不覆蓋新值。
- Given管制線採自動計算且三欄為空，When使用者只修改USL，ThenLCL／CL／UCL仍空白，圖表繼續使用原自動規則。
- Given輸入`100 ± 20`或`95%`，When執行預檢，Then系統不寫入並提示拆欄或移除符號。
- Given批次中一筆規格關係錯誤，When執行套用，Then整批不寫入；修正後重送才一次完成並留下逐筆版本／稽核。

## 例外與邊界

- Disabled項目仍顯示並可依權限編輯，但預設篩選為啟用；確認摘要須標示停用狀態。
- 一側規格空白是合法的單邊規格，不得自動補0或鏡射另一側。
- 分段規格存在時，主表只編輯基本值並顯示「另有分段」；不可把目前分段值回寫到基本值。
- 不支援手動界限的圖型欄位須唯讀；不能因欄位不適用而清空既有資料。
- 批次採預檢後原子套用；任一列過期或無效時整批不寫入，避免部分成功造成使用者誤認全部完成。
- 大量資料須分頁顯示，但dirty rows及預檢結果以PPC ID維持，不以列序或顯示名稱定位。
