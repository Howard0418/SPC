# 功能規格：藥液日報與非藥液量測隔離
- 功能 ID：SPC-CHEM-DAILY-SCOPE-1110-TASK-001
- 版本：1
- 狀態：完成
- 涉及專案：SPC API、Portal 藥液輸入
- 授權依據：2026-11-10 使用者回報正式 QE2 日報誤判重複並要求修正
- 現行需求基準：藥液日報只處理 `ControlScope=CHEM` 的管制項目；咬蝕量等 `PROCESS` 資料不得參與藥液日報重複判定
- 前案或相關規格：`specs/20261104-chemical-history-judgment/spec.md`

## 目的、現況與證據
正式 QE2 於 2026-11-05 有同日 50 筆咬蝕量子組資料。現行日報查詢只依線別、日期、班別、階段篩選，未限制管制範圍，因而把咬蝕量誤判為同一藥液項目的重複資料並回傳 409。

## 範圍與非範圍
- 修正藥液日報、月曆與 PortalDaily 寫入防重的管制範圍。
- Portal 將可辨識的 409 重複資料呈現為資料衝突，不再標成系統錯誤。
- 不刪除、不修改既有咬蝕量或藥液資料；不變更 schema、公式、F 表或規格上下限。
- 測試站驗證通過後依規則發布測試站；正式站另行授權。

## 需求與驗收
| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|
| R-001 | 藥液日報只讀取 CHEM 管制項目 | AC-001 | Given 同線同日只有多筆 PROCESS 咬蝕資料，When 載入藥液日報，Then 回 200 且 `exists=false`，不得回重複 409 |
| R-002 | 真正 CHEM 重複仍須阻擋 | AC-002 | Given 同一 CHEM 項目同日同班同階段有兩筆，When 載入，Then 回 409 `MEASUREMENT_MORNING_DUPLICATE` |
| R-003 | 月曆不得被非藥液資料標示 | AC-003 | PROCESS 資料不得產生藥液 `hasData` 或 `hasHistory` |
| R-004 | 寫入防重只適用 CHEM 映射 | AC-004 | PortalDaily 寫入不得以非 CHEM 映射執行藥液防重或寫入 |
| R-005 | 衝突訊息須可辨識 | AC-005 | Portal 收到上述 409 時顯示「資料衝突」及可處理說明，不顯示「系統錯誤」 |

## 例外與邊界
- `GENERAL` 舊班別相容規則與 N1/N2 開收線規則保持。
- 真正 CHEM 重複紀錄不得自動覆蓋或刪除。
- API／資料庫不可用等非業務衝突仍維持系統錯誤。

## 假設與未決問題
無阻擋性未決問題；正式發布待另行授權。
