# 功能規格：藥液量測排除計算／繪圖與調整參數
- 功能 ID：20261118-chemical-exclusion-and-adjustment-parameters
- 版本：9
- 狀態：已規劃／待逐項實作
- 涉及專案：Portal＋SPC
- 授權依據：使用者要求先規劃、加入小工作，不立即執行；2026-11-18 提供功能與備註選項。
- 現行需求基準：[需求索引](../../docs/requirements.md)
- 前案：[管制圖點位排除](../20261006-chart-point-exclusion/spec.md)、[藥液調整欄位隱藏](../20261117-chemical-hide-adjustment-columns/spec.md)

## 目的、現況與證據
Portal 負責藥液量測輸入，SPC 負責保存、運算與圖表。現有 SPC 已有量測點排除與計算器排除能力，但藥液錄入契約尚未提供本次排除旗標及指定備註；日報解析 DTO 已有槽容、添加管制值、稀釋管制值來源，但尚未確認新「藥液量測調整公式」頁面的持久化契約。

建議保留原始滴定值、分析值、判定及稽核追溯；排除只影響 SPC 統計、能力值、管制線／規則運算及圖表，不刪除量測，也不回寫既有資料。

## 範圍與非範圍
- Portal 新增／修改頁每一分析項目增加「不列入計算及繪圖」。
- 勾選時必選備註，暫定「當槽／無開線」、「收線」、「檢測／無開線」。
- Portal→SPC→資料庫保存排除旗標、備註代碼及操作者時間。
- SPC 所有藥液統計、管制圖、趨勢圖、能力值與 OOS/OOC 規則一致排除；查詢仍顯示資料與原因。
- 調整公式頁增加藥液、槽容(L)、添加管制值、稀釋管制值。
- 調整公式頁每個分析項目增加「備註」欄位；備註只作說明，不參與公式、調整量、判定或圖表計算。
- 調整公式頁可新增及修改資料；槽位、分析項目、規格與範圍沿用藥液量測新增頁的同一主檔來源先行帶入，不另建第二份主檔。
- 只有添加管制值或稀釋管制值的有效值實際改變時，儲存成功後通知品保與製程角色人員，提示是否需要另行調整規格及範圍；通知不得自動修改規格或範圍。
- 不刪除／批改舊量測，不恢復已隱藏調整欄，不改公式或三位小數規則。
- 本次只規劃，不修改程式、schema、資料或網站。

## BDD 行為
### Scenario：排除但保留追溯
Given 合法量測勾選排除並選擇原因；When 儲存；Then 原始值、分析值、排除狀態、原因與操作者均保存，
And 該筆不繪圖、不參與 SPC 統計。

### Scenario：排除原因驗證
Given 已勾選排除但原因空白或不合法；When 儲存；
Then 前後端拒絕該列，其他畫面值不被清除。

### Scenario：舊資料相容
Given 舊量測沒有新欄位；When 查詢或重算；
Then 視為正常納入，結果保持。

### Scenario：調整參數
Given 有權限人員選定藥液；When 修改槽容、添加與稀釋管制值；
Then 重載一致並留版本／稽核，不改公式與歷史量測。

### Scenario：公式頁備註
Given 有權限人員選定分析項目；When 輸入 500 字內備註並儲存；
Then 重載顯示相同文字並留版本／稽核，濃度公式、調整公式、調整量公式及計算結果完全不變。

### Scenario：沿用主檔新增調整資料
Given 藥液新增頁已有槽位、分析項目、規格及範圍；When 使用者開啟調整公式頁新增資料；
Then 四項資料與順序由相同主檔帶入，使用者只輸入調整參數及備註，保存不建立或修改另一份規格主檔。

### Scenario：管制值異動通知
Given 啟用品保及製程角色人員且添加或稀釋管制值已改變；When 儲存交易成功；
Then 每位有效收件人收到一次含前後值的私訊及「是否需要修改範圍、規格欄位資料」提示，規格與範圍本身保持不變。

## 例外與邊界
- 取消勾選時清除原因並稽核前後狀態；複驗不得自動取消排除或清空原因。
- 原因採穩定代碼保存、中文顯示。
- 參數建議大於 0；空白代表未設定，不以 0 代替。
- 批次保存不得因一列失敗清空其他列畫面值。
- 通知失敗不得回滾已成功提交的參數，但須留下不含Token與敏感內容的失敗原因及可重試依據。
- 數值比較採正規化後的 decimal 有效值；只有顯示格式不同但有效值相同時不通知。

## 假設與未決問題
- 非阻擋規劃：將文字解析為三個選項「當槽／無開線」、「收線」、「檢測／無開線」；若實際需拆詞，實作前修訂代碼。
- 非阻擋規劃：「不列入計算」解讀為不列入 SPC 統計／判定與繪圖，不是停止濃度換算；原始值與分析值仍保存。若要連分析值都不算，須另行確認。
- 參數是否直接參與兩式，第二件實作前須對照現行 Excel／公式契約，本次不自行接線。
- 備註格式建議使用多行自由文字而非下拉選單；它是分析項目公式／參數說明，與量測排除的三項原因不同。若日後需要固定分類，另以代碼欄規劃，不混用備註文字。
- 「通知」暫定使用既有 Synology Chat Bot 私訊，不同於 Email；若指定改用 Email，實作前修訂通道但維持相同收件角色與訊息契約。
- 建議訊息用語：「添加／稀釋管制值已修改，請確認是否需要同步修改範圍、規格欄位資料。」通知只提示，不提供會直接改主檔的按鈕。
