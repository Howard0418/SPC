# 藥液調整參數批次貼上計畫

- 主系統：Portal；相依系統：SPC 既有調整參數 API。
- 資料庫影響：無 schema；沿用既有逐筆保存與版本歷程。
- 實作：頁面增加貼上區、預覽表及批次儲存；依槽位＋分析項目配對目前線別。
- 正規化：全形空白轉半形、去除前後空白、配對鍵移除所有空白；數值欄須為大於 0 的數字。
- 空白政策：貼上空白欄位保留畫面既有值，不作清除；有標題列依欄名定位，無標題列採固定七欄。
- 儲存：預覽全數有效才可批次送出，逐筆呼叫既有 API；任何一筆失敗時停止後續項目並顯示已完成數，避免誤報全部成功。
- 發布：測試通過後發布 Portal 測試站；正式站另行授權。
- 回復：還原 Portal 頁面與前一版測試發布輸出；SPC API 不需回復。
