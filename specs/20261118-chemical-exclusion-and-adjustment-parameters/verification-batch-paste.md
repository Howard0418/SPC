# 藥液調整參數批次貼上驗證

## BDD

- Given 使用者已選線別且貼上 Excel 多列，When 按預覽，Then 系統依槽位＋分析項目配對，不依畫面列序。
- Given 儲存格含全形或多餘空白，When 解析，Then 顯示及配對使用清理後內容。
- Given 某個貼上欄位為空白，When 預覽及批次儲存，Then 該欄沿用目前值，不清除既有資料。
- Given 有重複鍵、找不到項目或無效數字，When 預覽，Then 顯示錯誤且不可批次儲存。
- Given 預覽全數有效，When 批次儲存，Then 沿用既有 API、版本歷程與管制值通知規則。

## 測試矩陣

| 類型 | 驗證 | 狀態 |
|---|---|---|
| Happy Path | 有標題列／無標題列、多列配對及保存 | 契約與語法檢查通過；待實站人工貼上 |
| Boundary | 全形空白、空白欄位、100字藥液、500字備註 | 程式分支與契約檢查通過；待實站人工貼上 |
| Invalid | 重複鍵、未知項目、零／負數／非數字 | 程式分支與禁止儲存檢查通過 |
| Regression | 原逐筆儲存、通知、唯讀規格範圍 | Portal Web 51項及Release build通過 |

## 自動驗證
