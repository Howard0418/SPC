# SPC公式日期選版與實際版本：Antigravity操作案例

環境：SPC https://spctest.pmr.com.tw/ （Web0.1.69／API0.1.67）；Portal https://portaltest.pmr.com.tw/Spc/VariableMeasurementEntry 。僅測試專用PPC及合法帳號，不操作正式站或KM，不輸出密碼／JWT。

## 準備
1. SPC管制項目設定選一個測試專用藥液PPC；公式A=`Primary*2`、精度2、依據`TEST-DOC-A`，儲存留下歷史；改公式B=`Primary*3`、依據`TEST-DOC-B`，再儲存。記下PPC ID及兩版號。
2. 公式生效排程：A為2026-10-01～10-18（迄日包含），B自2026-10-19起，發布。若需驗證F，另用測試專用F歷史快照B3=2，公式採`Primary*F!B3`，不要更動其他業務共用F版本。
3. 建立一段包含10/18～10/20的規格分段，界限涵蓋測試值；若需驗證規格邊界另用專用項目。排程不是規格分段，兩者用途不同。
4. TransFiles用`發布版_20261020_日期公式DB測試/BatchConvertTool.exe`。`PMR\ihao_ting`個人低權限測試連線已設定；用相同AD帳號正常登入Portal。請先選「建立原始值範本」，填下表；不是舊濃度匯入Excel。

## 案例
| 案例 | 操作 | 預期 |
|---|---|---|
| AG6-01 跨日直接匯入 | TransFiles「日期公式DB匯入（測試）」選上述Excel，核對預覽後確認 | 10/18初驗2.47、複驗4.69；10/19初驗3.7、複驗7.04（3.70與3.7數值相同，canonical不補尾零）。資料由SQL程序落地；Pending不等於統計完成 |
| AG6-02 統計查回 | 用「查詢日期公式統計狀態」選匯入結果JSON | 完成後顯示Completed。Failed需修正啟用圖表設定後等待重試，無須重匯；不得以反覆新增取代統計重試 |
| AG6-03 點日期分段 | SPC管制圖選該PPC及日期，點「日期分段與版本明細」的區間按鈕，或分段規格線 | 「區間量測與實際公式」列出各量測；明示多版本，初驗／複驗各自展開，版號／公式內容／依據與該日期預覽一致；不是目前公式B套整段 |
| AG6-04 單點與歷程 | 點管制圖單值點；另到藥液趨勢圖點該筆。分段中點「量測#…所有計算歷程」 | 用該點量測ID查證據；可看原始輸入、原始計算值、儲存值、量測時點及生效期間。「目前值／歷史留存」分開；下一頁不換量測ID |
| AG6-05 複驗修正 | Portal載入測試日報，修改原始值並重新預覽後確認；SPC重新查閱 | 同量測ID新增追溯版本，舊公式／原始值／結果保留，不覆寫。對應階段最新記錄標「目前值」；初複驗各自可查 |
| AG6-06 F／目前公式變動 | 在測試專用配置建立新F歷史或修改目前公式，不改已引用的歷史；回查既有量測 | 保存的公式內容、F歷史ID及引用B3值仍是原快照；查閱不重算。被引用歷史不可原地修改。可比較計算時規格快照，但不得聲稱有獨立管制界限版號 |
| AG6-07 舊資料／子組／非藥液 | 查舊量測；查Xbar-R/S多筆子組；查P/U等非藥液 | 舊資料明示無法確認，不補假版號；子組缺全部成員ID時不拿第一筆冒充唯一版本，可由分段逐筆查閱；非藥液不套藥液公式 |
| AG6-08 重送／錯誤／權限 | 同來源重送；改日期後使用舊預覽；清空Primary或填無時區日期；用Viewer查閱及嘗試確認 | 同內容重送回原量測，不重複；不同內容／過期／修訂衝突要求重新預覽。格式錯誤給工作表／列號與修正提示；Viewer可唯讀查閱、不能確認寫入。未登入API401 |

## 範圍與記錄
- 分段證據列的是此PPC日期範圍全部量測，不侷限圖表當前批次篩選；單點則以量測ID精確查。
- 當時計算規格判定與目前圖表可能因規格／取位不同而有差異；規格快照不是獨立版本號，管制界限當時版本未保存。不自動重算／回填舊資料。
- 自動化已包含SQL真實直寫／跨日選版／consumer／查閱，以及本機瀏覽器fixture；本文件真人正常SSO操作尚待執行。記錄PPC ID、來源檔、日期、量測ID、公式版號、F快照ID及觀察結果即可，勿提供密碼或token。
