# 功能規格：CPK 匯出月份資料範圍

- 工作代號：`REPORT-DATA-VERIFY-001`
- 狀態：執行中（2026-11-09）
- 優先級：P1
- 主系統：SPC；Portal／TransFiles／資料庫 schema 不變
- 發布：測試站通過後自動發布；正式另行授權

## 問題與基準

「品質履歷查詢」頁提供月份選擇器，畫面文字明示下載「該月份統計報表」。現行 API 僅把 `month` 寫入標題與檔名，量測、警報、違規及各項 CPK 都查全部歷史，造成標示月份與資料範圍不一致。

## 規則

- `month` 僅接受 `yyyy-MM`；格式或不存在月份回 400，不得靜默改用其他月份。
- 未提供月份時，使用台北時區目前月份。
- 月份範圍採台北月初 00:00（含）到次月月初 00:00（不含），轉成 UTC 查詢。
- 總量測、違規與每個 PPC 的平均／標準差／Cp／Cpk 只使用該月份的計量量測；警報只計該月發生者。
- 沒有該月量測的已啟用 PPC 仍列出並標示未檢測，避免把「無資料」誤當成主檔缺漏。
- 不改公式、規格、量測、計算結果或其他匯出。

## BDD

- Given 九月與十月各有同一 PPC 量測，When 匯出 `2026-10`，Then 平均值、總量測只採十月資料，檔名與標題同為 2026-10。
- Given 台北時間 10/01 00:00 邊界資料，When 匯出九月及十月，Then 該筆只出現在十月。
- Given `2026/10`、`2026-13` 或空白字串，When 匯出，Then 明確拒絕格式錯誤，不產生內容與誤導檔名。

## 測試風險

- Happy Path：單一月份多筆量測及能力值。
- Boundary：台北月初／次月月初 exclusive upper bound。
- Invalid Input：錯誤格式、無效月份。
- Regression：未提供月份仍可下載；其他月份資料不改；正式站不發布。
