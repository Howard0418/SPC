# 小型變更：作業人員頁面權限總覽

- 版本：2
- 狀態：測試站已發布並由使用者確認驗收通過
- 專案／授權依據／需求基準：SPC；2026-11-20 使用者要求在作業人員主檔直接看出每人的頁面權限。

## 問題、預期行為與範圍
- 現行列表只顯示 Viewer／Editor 角色，無法直接判斷每位人員實際可使用的頁面。
- 列表新增「頁面權限」欄，依 `/api/operators` 回傳的解析後權限碼與權限目錄顯示中文頁面名稱及數量。
- 已移除的設備頁面不顯示；未知但仍由 API 回傳的權限碼保留顯示，避免資訊被隱藏。
- 不修改角色、權限判斷、資料庫、Portal 或既有新增／編輯／刪除功能。

## 需求與驗收
- R-001：每位人員列直接顯示完整頁面權限名稱及「共 N 項」，移除展開控制與「點此查看」。
- AC-001（Happy Path）：Given 一位人員有頁面權限，When 列表載入，Then 不需點擊即可看到權限數量和所有名稱。
- AC-002（Boundary）：Given 無頁面權限，Then 顯示「無頁面權限」。
- AC-003（Invalid/相容）：Given API 回傳目錄外權限碼，Then 仍顯示原權限碼；已移除設備頁面不顯示。
- AC-004（Regression）：搜尋、狀態篩選及人員新增／編輯／刪除行為保持。
