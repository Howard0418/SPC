# 小型變更：Portal 測試生日祝賀按鍵規劃
- 功能 ID：PORTAL-BIRTHDAY-PREVIEW-BUTTON-20261012
- 版本：1
- 狀態：已完成規劃
- 專案／授權依據／需求基準：PmrPortal；依使用者 2026-10-12 指示，先規劃並加入小工作，不立即實作；參照 `specs/20261007-portal-birthday-replan/`、`docs/requirements.md` 與 `CHANGELOG_CUSTOM.md` 既有生日通知需求。

## 問題、預期行為與範圍
- 現況：Portal 已有人事專區生日祝詞與祝賀圖片設定，登入生日通知會套用設定內容；但測試版面與顯示效果仍依生日日期觸發，不方便人事或測試者即時確認。
- 問題：若要確認生日通知版面、圖片、祝詞與關閉效果，需等待特定生日條件或調整資料，測試成本高。
- 預期：在人事生日通知設定頁建立「測試生日祝賀」按鍵，點擊後立即顯示與正式生日通知相同內容的廣告式彈窗，可用關閉按鍵關閉。
- 範圍：本次只建立規劃與小工作；不修改 Portal 程式、不建置、不發布。

## 需求與驗收
- R-001：Portal 人事生日通知設定頁需提供測試生日祝賀按鍵，限有權限維護生日通知設定者使用。
- R-002：點擊測試按鍵後，不需符合生日日期或指定時間，直接顯示生日祝賀預覽。
- R-003：預覽呈現需像購物網站廣告彈窗，覆蓋目前頁面或以明顯 modal 顯示，包含祝賀圖片、祝詞與關閉按鍵。
- R-004：預覽只影響目前瀏覽器畫面，不寫入生日通知已讀狀態、不發送通知、不修改使用者生日資料。
- AC-001：Given 人事使用者在生日通知設定頁，When 點擊測試生日祝賀，Then 立即看到生日祝賀彈窗。
- AC-002：Given 彈窗已顯示，When 點擊關閉按鍵，Then 彈窗關閉且頁面可繼續操作。
- AC-003：Given 今天不是登入者生日，When 點擊測試生日祝賀，Then 仍可顯示預覽，且不改變正式生日觸發規則。
- AC-004：Given 測試生日祝賀顯示，When 檢查資料寫入，Then 不新增通知紀錄、不修改生日資料、不影響正式登入通知狀態。

## BDD 驗收
### Scenario: 人事即時預覽生日祝賀
Given 人事使用者已進入 Portal 生日通知設定頁
When 點擊「測試生日祝賀」按鍵
Then 系統立即顯示套用目前祝詞與圖片的生日祝賀彈窗

### Scenario: 使用者關閉預覽彈窗
Given 測試生日祝賀彈窗正在顯示
When 使用者點擊關閉按鍵
Then 彈窗消失且不重新載入頁面

### Scenario: 預覽不影響正式通知資料
Given 今天不是登入者生日
When 人事使用者點擊測試生日祝賀
Then 系統只顯示預覽，不寫入通知已讀或生日資料異動
