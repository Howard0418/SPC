# 功能規格：日期公式匯入環境與資料契約核對
- 功能 ID：FORMULA-IMPORT-001
- 版本：1
- 狀態：完成
- 涉及專案：SPC、TransFiles（獨立轉檔工具）
- 授權依據：使用者要求執行下一個小工作；沿用「先以測試資料庫為主、不可直接更新正式機」限制。
- 現行需求基準：[日期公式 DB 匯入環境與版本歷史](../20261029-chemical-formula-db-import-environment-history/spec.md)
- 前案或相關規格：[日期公式原始值 DB 直寫](../20261020-formula-trace-task005/spec.md)

## 目的、現況與證據

日期公式匯入已具備 SPC preview／prepare 收據契約，以及 TransFiles 測試／正式 API 白名單與正式二次開關。此工作僅驗證契約是否能阻止錯環境、缺少時區及缺少原始量測值的輸入；不進行資料匯入。

## 範圍與非範圍

- 範圍：補充 TransFiles 隔離測試；確認 SPC preview／prepare 的登入、Editor 寫入權限與「只建立收據、不寫量測」責任界線；記錄 API 資料格式。
- 非範圍：公式差異比對與新版本建立（FORMULA-IMPORT-002）、GUI 預覽（003）、Portal 代理（004）、測試站發布與人工驗收（005）、任何實際 API 呼叫、資料庫寫入、正式設定或打包。

## 需求與驗收

| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|
| R-001 | 僅接受已核准的測試／正式 SPC API 根網址；選擇正式仍須明確啟用。 | AC-001 | 測試根網址可建立 client；環境／網址不一致與未啟用正式皆被拒絕。 |
| R-002 | 每列必須含 ISO 8601 時區、原始 Primary 數值、有效 PPC、班別／階段與可追溯來源鍵。 | AC-002 | 合格列保留原始數值與來源鍵；無效日期、空值、NaN、無時區、無效 PPC／班別被拒絕。 |
| R-003 | SPC 預覽不寫量測；prepare 僅在登入且 Editor／Admin 權限下建立短期收據。 | AC-003 | 既有 SPC 隔離測試證實 preview 無量測寫入、prepare 受 Editor 權限保護。 |

## 例外與邊界

- 正式 URL 即使可識別，未傳入 `allow_production=True` 必須拒絕。
- URL 大小寫或尾斜線以正規化比對；非白名單 host 不可透過字串相似性通過。
- 本件不得將「隔離測試通過」表述為實際檔案已成功匯入。

## 假設與未決問題

無阻擋本件隔離驗證的未決問題。正式匯入授權及實際公式差異寫入留給後續工作。
