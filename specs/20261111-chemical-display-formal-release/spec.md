# 功能規格：藥液日報顯示修正正式發布

- 功能 ID：`PORTAL-CHEM-RAW-INPUT-1111-FORMAL-RELEASE`
- 版本：1
- 狀態：已發布，待登入後業務畫面驗收
- 涉及專案：SPC、Portal
- 授權依據：使用者於 2026-11-11 明示「授權更新正式區」。
- 現行需求基準：[藥液日報原始滴定值顯示與第二輸入收斂](../20261111-chemical-entry-raw-input-display/spec.md)
- 前案或相關規格：同前案測試站驗收、[正式發布工具](../../20261019-production-release-tool/spec.md)。

## 目的、現況與證據

將已在測試環境驗證的藥液日報原始滴定值回填、保存值顯示規則、第二原始值欄位收斂，以及必要的 SPC 入口與 Portal 人員比對修正，發布至正式環境。測試 SPC API 為 0.1.125、Web 為 0.1.127；正式 SPC API 為 0.1.104、Web 為 0.1.118。藥液輸入頁位於 Portal，需同時發布對應 Portal API 1.0.230 與 Web 1.0.271 的既有已驗收來源。

## 範圍與非範圍

- 範圍：SPC 與 Portal 的 API／Web 二進位與靜態資產正式發布、備份、回復及連線驗證；使用者後續明示授權的 SPC 3 項與 Portal 1 項既有 EF migration。
- 非範圍：量測、Receipt／Trace、藥液公式、F 表、規格、判定、主檔或匯入資料的新增、修改、重匯與刪除；migration 僅新增稽核／界限歷程及使用者語系偏好所需 schema，不進行業務資料修補。
- 非範圍：發布未經驗收的測試專用功能，或覆蓋 `D:\Sites\PmrPortal`。

## 例外與邊界

- 任一 Plan、備份、migration、套用或 smoke 失敗，發布工具必須回復應用程式並保留私有證據；不可宣稱正式發布完成。
- 正式登入後的完整業務畫面驗收需另以具權限帳號操作；HTTP 成功不替代此驗收。

## 假設與未決問題

無阻擋性業務規則。正式資料庫啟動授權視同本次正式發布授權的一部分，僅用於工具的備份、遷移預檢與應用程式啟動，不授權資料修補。
