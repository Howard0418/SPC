# 儀器主檔補齊規格與校驗資訊
- 功能 ID：20260916-calibration-details
- 版本：1；狀態：測試站已發布
- 授權：使用者反映缺少量測規格、精度、備註、校驗規範、允收標準。
- 基準：[儀器匯入](../20260911-instrument-calibration-import/spec.md)、[校正主檔](../20260911-instrument-calibration/spec.md)。
## 現況與範圍
五欄尚未進入 Entity/API/匯入。原始 Excel F/G/AB/AC/AD 欄已有資料。僅 SPC，保留日期、通知、校正歷史與既有匯入僅新增規則。
## 需求與驗收
- R-001／AC-001：主檔新增五個可空文字欄，列表顯示、新增/編輯可儲存；保留換行，備註與校正紀錄理由分開。
- R-002／AC-002：Excel F/G/AB/AC/AD 依表頭讀取並在預覽顯示、提交保存；舊範本沒有新增表頭仍相容，錯誤表頭有值不可錯置。公式採有效儲存值並警示。
- R-003／AC-003：每欄最多 2000 字，超長/公式錯誤拒絕，空白存 null，API 稽核保留。
- R-004／AC-004：測試庫既有儀器以原 Excel 完全相符的編號/名稱只補空白欄；交易、來源 hash 與逐筆稽核，可重跑不覆寫、不改日期/狀態/通知/歷史。正式庫不處理。
## 假設
五欄為文字資訊，不新增自動合格判定。既有已填內容不覆蓋。
