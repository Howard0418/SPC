# 功能規格：藥液量測有效分析值一致顯示
- 功能 ID：SPC-CHEM-EFFECTIVE-VALUE-1113-TASK-001
- 版本：1
- 狀態：實作中
- 涉及專案：SPC（主系統）、Portal（相依系統）
- 授權依據：2026-11-13 使用者要求「請一定要保持資料一致，圖的來源也是」。
- 現行需求基準：[藥液歷史查詢／圖表有效值一致](../20261111-chemical-query-chart-value-alignment/spec.md)
- 前案或相關規格：[原始輸入顯示](../20261111-chemical-entry-raw-input-display/spec.md)

## 目的、現況與證據

已保存量測的有效分析值為 `RecheckValue ?? MeasuredValue`。SPC 統計與圖表使用此值，Portal 查詢也讀取 API 的 `effectiveValue`。Portal 日報載入畫面卻將初驗欄標為「分析值」，而複驗有效值只在另一欄顯示；例如同筆初驗 12.18、複驗 12.41，使用者容易誤以為查詢／圖表的 12.41 與新增頁不一致。

本次只修正入口畫面對已保存有效值的明確呈現，初驗及複驗證據均保留，不以現行公式回算或改寫歷史資料。

## 範圍與非範圍

- 範圍：Portal 藥液量測日報的初驗欄明確命名，並顯示與查詢／SPC 圖表相同的最終分析值及來源（初驗或複驗）。
- 範圍：以自動化測試固定 API 查詢、入口頁與 SPC 統計共用 `RecheckValue ?? MeasuredValue` 的契約。
- 非範圍：不變更公式、調整計算、資料庫 schema、既有量測資料、圖表演算法或正式站。

## 需求與驗收

| 需求 ID | 業務規則 | 驗收 ID | 可觀察的通過條件 |
|---|---|---|---|
| R-001 | 唯一有效分析值為已保存的 `RecheckValue ?? MeasuredValue`；複驗值 0 仍為有效複驗值。 | AC-001 | Given 初驗 12.18、複驗 12.41，When 載入日報，Then 顯示初驗 12.18、複驗 12.41，且「最終（查詢／圖表）」為 12.41／複驗。 |
| R-002 | 無複驗時最終分析值使用初驗。 | AC-002 | Given 僅有初驗 12.18，When 輸入或載入，Then 最終值為 12.18／初驗。 |
| R-003 | 歷史載入與圖表只讀保存值，不能用當前公式重算或寫回。 | AC-003 | Given 已保存歷史資料，When 載入頁面與查詢／圖表，Then 不發出預覽計算請求、不變更保存值，且皆使用相同有效值。 |

## 例外與邊界

- 初驗及複驗皆空白時，最終值顯示「待輸入」。
- `0` 不可被當成空值；有複驗 0 時來源必須標為複驗。
- 歷史判定仍依保存的追溯／規格證據，不因本次顯示修正改判。

## 假設與未決問題

無。使用者已明確指定一致性規則；本次以現有後端有效值契約為唯一來源。
