# 十月藥液資料與三個公式唯讀核對
- 功能 ID：SPC-CHEM-RECONCILE-1103
- 版本：1
- 狀態：唯讀核對及附件驗證完成；不是公式修正或歷史資料重算
- 授權：使用者「其他的藥液項目，資料跟3個公式都要再對一次」。沿用十月先行、九月先不補、缺實際時間／班別不得正式匯入的規則。

## 問題、範圍與基準
- PT1／粗化／銅離子已證實舊遷移使用固定係數重建公式，漏掉 F!B6。不能用固定係數互相比較取代 Excel 原式／各日期 F 的獨立核對。
- 主系統 SPC；唯讀參考 Portal 舊公式規則及 TransFiles 來源定位。核對正式與測試既有業務主檔、十月日報原檔及指定範本的濃度、調整判斷、調整量公式，包含初驗／複驗。
- 正式／測試 SQL 僅 SELECT；來源 Excel 只讀。不得執行匯入、重算、公式／F 更新、schema／設定變更、網站或工具發布。
- 依線別、槽位、分析項目、單位唯一配對；日期、線別衝突及多候選隔離，不能靠數值或列位置強配。
- 保存原式、F 參照／值、來源檔案／工作表／儲存格、日期、網站公式及保存值。數值全精度、保存／顯示精度分開比較。

## 驗收與核對方法
- AC-001：十月清單內所有來源檔重新確認 hash、公式及快取；範本所有線別納入，列出沒有十月資料或無唯一主檔的項目。
- AC-002：三式分別比較。Given 濃度引用 F，When 網站改成數值係數，Then 即使當日結果相同仍標記「F 參照未保留」。
- AC-003：Given 原始滴定值／F 與 Excel 快取，When 獨立運算，Then 與網站現公式結果、資料庫保存值分別比對；缺參數／計算能力／歷史版本者明示未確認，不當通過。
- AC-004：Given 初複驗公式或閾值不同，When 比較三式，Then 分開記錄原式、實際結果及邊界差異，不以初驗代替複驗。
- AC-005：來源異常、資料缺漏、重複候選、精度差異與追溯不足分列，附可定位的調整建議，不自動修補。
- AC-006：SQL 前後保護指紋及來源前後 hash 相同；核對附件內容、涵蓋數量、來源定位與抽樣重算驗證通過。
- Happy Path：唯一配對、三式與數值相符；Boundary：0／空白、閾值及兩側、初複驗差異；Invalid：#REF!、缺 F、日期／線別衝突、多候選；Regression：既有主檔、資料及來源不變。
