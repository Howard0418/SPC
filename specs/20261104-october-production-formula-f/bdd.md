# BDD：十月藥液公式與 F 表正式匯入

功能 ID：`SPC-CHEM-F-CONSISTENCY-1103-TASK-001-PROD-OCT`
來源規格：[spec.md](spec.md)
版本：1

```gherkin
Feature: 十月藥液公式與F表正式受控匯入
  為了讓十月正式藥液資料使用當日正確公式與F值
  作為正式匯入操作者
  我需要可追溯、不可重複且不影響量測的公式/F版本

  Scenario: 唯一映射後建立正式日期版本
    Given 來源檔雜湊不變且線別槽位項目單位唯一對應正式PPC
    When 在已驗證備份後套用公式與完整F快照
    Then 每個報表日可選到唯一公式與F歷史且代表值與Excel一致
    And 不建立任何量測資料

  Scenario: 相同清單重送
    Given 相同公式、F快照與排程已存在
    When 再次執行同一正式清單
    Then 結果為NoChange且版本與revision數量不增加

  Scenario: 同日來源公式F衝突
    Given 同一正式PPC與日期有兩個不同公式或完整F快照
    When 建立正式套用計畫
    Then 該PPC日期的來源全部隔離且不選任一版本
    And 其他唯一可確認群組仍可進入受控交易

  Scenario: 正式環境或既有排程衝突
    Given 來源hash改變、主檔映射歧義或既有排程內容不同
    When 嘗試正式套用
    Then 在交易提交前拒絕且正式資料不變

  Scenario: 現行主檔保持
    Given 正式PPC目前公式及啟用F主表已存在
    When 套用十月歷史公式與F快照
    Then 目前PPC配置與啟用F主表完全不變
```

## 驗證對應

| Scenario | 自動化測試或人工驗證 | 狀態 |
|---|---|---|
| 唯一映射後建立正式日期版本 | runner單元／整合測試＋正式寫後試算 | 通過：1199 列／80 PPC、81 公式、3 F 快照及 1039 日別區間 |
| 相同清單重送 | 二次執行報告 0 新增 | 通過：`VERIFIED_NO_CHANGE`，四類新增皆 0 |
| 同日來源公式F衝突 | 群組完整隔離測試 | 通過：6 群組／12 列完整隔離，不選 OPEN 或 MIDDLE 勝者 |
| 正式環境或既有排程衝突 | 錯環境／歧義／既有異質排程測試 | 通過：非正式身分與異質既有排程均在建立新歷史前拒絕 |
| 現行主檔保持 | 寫前寫後配置與啟用F指紋 | 通過：目前 PPC、啟用 F 及保護資料指紋均相同 |
