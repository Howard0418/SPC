PMR 系統更新工具 1.1.0

1. 雙擊 PMR.ReleaseUpdater.exe，同意 Windows 系統管理員提示。
2. 選擇「測試環境／正式環境」及「SPC／Portal」。
3. 沒有 manifest.json 時，按「製作交付包…」：
   選擇已編譯的 API／Web 發布資料夾，讀取來源版本與 commit，填寫 Web 版本。
   按「從目標讀取現行版本」，或依實際部署版本填寫；選擇輸出位置與唯一批號。
   如有資料庫變更，提供已審查 SQL 與核准 migration ID；沒有變更則留空。
   按製作後自動產生 manifest.json、ZIP 與逐檔 SHA256，並帶回主畫面。
4. 已有交付包可直接選 manifest.json；ZIP／SQL 必須保留在同一交付目錄。
5. 按「執行預檢」，確認環境、主機、資料庫、版本及結果。
6. 確認本次應用與資料庫／啟動授權後勾選兩項，按「開始更新」，核對確認視窗。
7. 等候完成，再登入驗收；執行期間不可關閉程式。

製作交付包不會更新網站或資料庫，不會自動執行更新。
API 版本、commit、migration 清單由靜態 metadata 讀取，不執行 API。
來源須為已編譯發布檔；SPC 前端須先依目標環境 build，工具不改寫前端環境。
來源缺少 commit 時需填入開發者提供的真實完整 commit，不可任意編造。
SPC 舊 Web 由備份 hash 驗證，不需填寫舊 Web 版本。
輸出目錄已存在時拒絕覆蓋；失敗留下的 .incomplete 目錄不作正式交付包使用。

回復：選擇同一批原 manifest，確認兩項授權後按「回復此批應用」。
只回復應用；資料庫 schema 與新增檔保留，不自動還原整庫。

需求與限制：
- 單一 EXE，操作端不需 SDK 或 PowerShell7；需 Windows x64／.NET Framework4.8／Windows PowerShell5.1。
- 使用目前 Windows 帳號，須具目標 WinRM／IIS／DB 權限，不儲存密碼、不修改執行原則。
- EXE 未簽章；請核對交付來源及 SHA256SUMS.txt。
- 內建工具抽取至 ProgramData\PMR-Release-Updater 私有目錄，暫存／備份不自動清除。
- 交付 EXE 不代表已更新站台；更新／回復須由操作人員核對本次範圍。
