# 任務目標：為 MES + SPC 網站製作次世代全功能互動教學手冊 (Rich HTML User Manual)

## 1. 角色設定
請扮演頂級企業軟體架構師與使用者體驗專家 (UX Specialist)，為我們的 MES + SPC 智慧工業品質網站編寫一份給「產線主管、品管工程師 (QE) 與系統管理員」看的操作教學手冊。

## 2. 專案背景與檔案位置參考
- 前端專案位於：`C:\Users\ihao_ting.PMR.000\Desktop\MES\frontend\mes-spc-web\` (Vue 3 / Vite)
- 請務必檢視路由定義檔與核心視圖 (如 `SpcChartView.vue`, `ControlChartTypesView.vue`, `Alerts.vue`)，以確保功能名稱與實際操作步驟完全契合。

## 3. 核心功能涵蓋範圍 (請依序分章節撰寫)
1. **基礎品質主檔維護**：如何設定產品、製程與料號特性關聯表 (USL / LSL / Target)。
2. **管制圖種類與公式維護**：如何在系統中切換「標準全距法」與「平均值移動全距法 (MR-Method)」，以及 JSON 配置檔結構說明。
3. **即時互動戰情室操作**：如何輸入批次 UUID 進行追溯、檢視紫色脈衝光澤徽章與解讀 UCL/LCL 統計界限。
4. **異常通報與閉環處置**：如何查看 OOS/OOC 警報單號，並在 V2 工作流中更新 Open -> In Progress -> Closed 處理進度。

## 4. 自動化截圖授權 (Browser Action Required)
請先使用 `browser_subagent` 啟動並訪問本地端開發伺服器 (如 `http://localhost:5173/` 或對應路由)，依序進入各主檔頁面與戰情室，擷取高品質操作截圖，並將這些絕對路徑圖片完美嵌入教學文件中。

## 5. 輸出格式標準 (Anthropic HTML Standard)
請不要輸出冰冷的純文字 Markdown。請幫我產出一個單一的高級 HTML 檔案 (`spc_user_manual_portal.html`)，需具備：
- 玻璃擬態 (Glassmorphism) 與深淺模式切換 UI。
- 左側主題導覽列與頂部關鍵字即時快搜。
- 內建一鍵列印轉存 PDF 按鈕與完美列印排版。
- 內嵌 SPC 公式試算沙盒與異常狀態切換互動演練區。

🔒 鎖定檔案路徑 (Grounding)

指明前端檔案位置 (`mes-spc-web`)，能引導 Antigravity 在回答前先去 `view_file` 或 `grep_search` 您的真實程式碼（例如查看 `SpcChartView.vue` 中的變數名稱），確保寫出來的操作按鈕名稱 100% 正確無誤。

🤖 授權 Browser Subagent

明確要求使用 `browser_subagent`，這會啟動內部的自動化無頭瀏覽器，前往您的網站點擊按鈕並拍下真實畫面。這省去了您手動貼圖的繁瑣流程。

📄 指定 Anthropic HTML 輸出

要求輸出單頁式 HTML 搭配列印轉存按鈕，保證了最後產出的手冊不只好看，還能直接發給全廠員工在瀏覽器開啟，或是秒轉為精美的 PDF 報告。

📌 劃分清晰的四大模組

將系統功能明確拆解為「主檔、公式、戰情室、異常處置」，能讓 AI 產出的結構井然有序，不會遺漏任何一個重點。
