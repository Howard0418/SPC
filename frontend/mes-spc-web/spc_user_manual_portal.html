工業品質系統全場景操作指南

歡迎進入 MES + SPC 智慧工業品質平台操作手冊。本手冊完整收錄從「底層檢驗項目設定、客製化公式 JSON 套用」到「線上互動戰情室數據追溯與 V2 異常處置閉環」的四大核心步驟。

第 1 章：基礎品質主檔與檢驗基準設定

建立料號 (Part)、製程 (Process) 與量測特性 (Characteristic) 的規格上下限 (USL / LSL / Target)

在系統開始進行 SPC 繪圖與異常偵測前，必須先設定檢驗基準。請依下列步驟進行操作：

  1. 1
    登入系統後，展開左側導覽列的 「品質主檔與檢驗設定」，點選 「料號製程檢驗基準維護」。
  2. 2
    在上方篩選欄位選擇對應的 產品型號 (Product) 與 檢驗站別 (Station)。
  3. 3
    於表格右側點擊「編輯」，輸入該特性的 規格上限 (USL)、規格下限 (LSL) 與 目標值 (Target) 並按下儲存。
提示：系統支援批量匯入 Excel/CSV 檢驗基準，省去人工逐筆輸入的時間。

第 2 章：管制圖種類與動態公式配置 (JSON Master)

透過 JSON 彈窗一鍵切換「標準全距法」與「平均值移動全距法 (MR-Method)」

為滿足半導體與車用電子供應鏈多樣化的統計需求，系統內建了動態公式引擎。當抽樣樣本數 $N=1$ 或需要特殊移動差值分析時：

  1. 1
    前往左側導覽列點選 「SPC 管制圖配置」 -> 「管制圖種類維護」。
  2. 2
    在代號 XBAR_R 的資料列點擊右側的 「編輯公式」，系統會彈出設定視窗。
  3. 3
    彈窗上方提供了三種快捷按鈕：除了標準全距法外，點擊 「🧪 平均移動全距法 (MR-Method)」 或 「🧪 樣本標準差法 (Sigma-Method)」，系統將自動填入對應的 JSON 設定檔。
    MR-Method: UCL = Xbar + 2.66 * MRbar Sigma-Method: UCL = Xbar + 3.0 * S_Xbar
動態 JSON 結構解析 (以 Sigma-Method 為例)
"XbarCalculationMethod": "SIGMA_METHOD"
"Multiplier": 3.0
"UclFormula": "XDoubleBar + (3.0 * S_Xbar)"

第 3 章：即時 SPC 互動戰情室 (War Room)

輸入批次 UUID 追溯量測點、檢視紫色脈衝光澤徽章與雙列日期時間呈現

戰情室沙盒同步中

戰情室是工廠品質監控的核心樞紐。當切換至 MR-Method 公式時，頁面將具備以下智慧視覺特徵：

  1. 1
    前往左側導覽列的 「即時品質看板」 -> 「即時 SPC 戰情室」。
  2. 2
    在頁面上方選擇料號與製程，或直接輸入指定批次的 UUID 進行歷史數據快速調閱。
  3. 3
    若當前生效公式為移動全距法，圖表頂端會自動亮起「🧪 截圖公式：平均移動全距法 (2.66 * MRbar)」的紫色脈衝徽章。
優化體驗：圖表的 X 軸標籤已同步升級為 `MM/DD HH:mm` 精準格式，完美兼顧長天期與跨班次的時間判讀。

第 4 章：異常通報總覽與 V2 閉環處置工作流

即時追蹤 OOS / OOC 品質違規警示，並更新處理進度達成完整審核閉環

IATF 16949 Compliant

當系統計算發現數值超出規格 (OOS) 或違反西方電氣規則 (OOC) 時，將發布異常單。工程師需透過以下步驟進行追蹤與結案：

  1. 1
    前往左側導覽列 「異常管理與追溯」 -> 「異常通報總覽」 檢視所有觸發事件。
  2. 2
    點選 「V2 異常流程」，利用頂部的 Status 篩選器尋找指派給您的 Open 單號。
  3. 3
    在單號的 狀態 欄位輸入進度（如 處理中 或 Closed），點選右側的 「更新流程」 完成簽核。
