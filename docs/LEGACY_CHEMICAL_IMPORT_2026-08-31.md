# 舊藥液資料匯入整理（測試區）

日期：2026-08-31  
目標環境：SPC 測試區（API 8081）

## 原則

- 現行啟用中的 CHEM PPC（線別、槽位、分析項目、單位、規格）是唯一主檔依據。
- 舊檔的規格與範圍只協助辨識來源組合，不得回寫或覆蓋現行 PPC 規格。
- 對應鍵使用「線別 + 舊槽位 + 舊分析項目 + 單位 + 舊規格範圍」，避免同名分析項目被全域誤換。
- 只有唯一且高信心的對應可自動進入預覽；歧義、找不到現行 PPC、缺量測值者一律隔離。
- 同一 PPC 與量測時間有多筆舊紀錄時，以遞增 `SampleNo` 保留各筆資料。

## 程式保護修正
