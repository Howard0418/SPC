# 2026 年 8 月咬蝕量匯入整理（測試區）

## 主檔與轉換規則

- 使用既有 PROCESS 品質特性：`ETCH_A_AVG`、`ETCH_B_AVG`、`ETCH_RATE`，不建立重複分析項目。
- 適用線別：PT1、PT2、QE1、QE2，共 12 個啟用 PPC。
- 舊檔 `+01～+25` 視為 A side，取有效數字平均並四捨五入至小數第 3 位。
- 舊檔 `-01～-25` 視為 B side，取有效數字平均並四捨五入至小數第 3 位。
- 咬蝕速率只採用舊檔既有有效數字；`#DIV/0!`、空白或非數字不匯入。
- 舊檔規格不回寫現行 PPC，SPC 判定以現行主檔為準。
