## 用量與接續

每輪只指定一張工作卡；先核對目前工作區及規格狀態，再執行必要工作。每輪結束記錄已完成、待辦、驗證、發布及下一個動作。無法讀取帳戶剩餘 token 或重置時間，排序不代表用量預測；接近額度時只做交接摘要，重置後從該卡繼續。

## 用量分級排程

每次開始工作前先查看 Codex `/status`。剩餘用量只作為工作範圍控制，不代表精確工時估算。

| 剩餘用量 | 本輪可做的工作 |
| --- | --- |
| 70% 以上 | 新功能、跨系統規劃，或一張完整工作卡的實作與必要驗證 |
| 40%～70% | 單一系統功能、API 或畫面修正；只處理一張工作卡 |
| 20%～40% | 小型修正、既有功能驗收、測試或文件同步 |
| 20% 以下 | 停止開發，只整理交接摘要；不開新範圍、不發布 |
| 無法取得用量 | 採保守模式，只做盤點、規格或交接整理 |

### 每輪開始 Prompt

```text
請先查看目前 Codex 用量狀態。
依剩餘用量選擇本次工作：70%以上可執行完整工作卡；
40%～70%只執行一張單一系統工作卡；20%～40%只執行小型修正或驗收；
20%以下停止實作，改做交接摘要。
若無法取得用量，採保守模式，只做盤點或規格工作。
本次只處理工作卡：[W01]
依各專案 AGENTS.md 與 SDD 流程執行，不擴大範圍。
```

### 用量快用完 Prompt

```text
請停止目前工作，停在安全節點。
只輸出精簡交接摘要：已完成、尚未完成、修改過的檔案、
驗證與發布狀態、對應的 SDD 規格、下次重置後的第一個動作。
不要開始新功能，不要發布。
```

### 重置後接續 Prompt

```text
用量已重置，請依上一輪交接摘要接續。
先核對目前工作區與 SDD 狀態，避免重做已完成項目。
只繼續原工作卡：[W01]；完成後才處理下一張工作卡。
```

### 固定節奏

高用量時做規劃與核心開發；中用量時完成一張單一工作卡；低用量時做驗收、測試與文件同步；接近上限時只交接。重置後先接續未完成工作，再開始下一張。
