# Full System Test Cases (FPC Smart Factory SPC)

以下為根據 SPC/MES/Traceability 架構設計之完整測試案例庫。測試資料需加上 `TEST_` 前綴，並且不可污染或合批 (Merge Lot) 正式資料。

| 編號 | 測試項目 | 測試描述 | 預期結果 |
| :--- | :--- | :--- | :--- |
| TC-BAS-001 | 登入與權限 | 測試不同角色登入。 | 依角色顯示可用選單，無權限 API 回傳 403。 |
| TC-BAS-002 | 主選單導覽 | 點擊側邊欄所有子項目。 | 畫面切換正常，無 404 錯誤。 |
| TC-BAS-003 | 主檔查詢與過濾 | 使用關鍵字查詢料號與製程。 | 列表正確顯示符合條件之資料。 |
| TC-BAS-004 | 新增與修改資料 | 新增 `TEST_PART` 並進行名稱修改。 | 資料正確寫入資料庫並即時反映於列表。 |
