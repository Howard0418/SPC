# 11 已知問題與修復紀錄 (Known Issues & Fixes)

## 已修復問題 (Resolved Issues)

1. **實體 SQL Server 遷移與 unique 索引衝突**：
   - **問題**：重複執行資料庫種子或遷移時，因有多個中分類（如 `VAR_PROC`, `VAR_CHEM`, `VAR_PROD`）重複登錄 `XBAR_R`/`XBAR_S`/`I_MR` 管制圖小分類代碼，觸發資料庫唯一約束衝突。
   - **修復**：修改為在寫入前同時向 EF Core `ChangeTracker.Local` 以及實體資料庫查詢以進行重複校驗，保證全局僅寫入一份代碼。
2. **圖表類型精確判定**：
   - **問題**：以前使用模糊的 `Contains` 進行判定，導致 `IX-MR` 會被誤認含有字母 `R` 而對應到 `XBAR_R`。
   - **修復**：改為精確的 `string.Equals()` 並配合 Fallback 機制，確保 `IX-MR` 與 `I_MR` 正確映射到單值-移動全距圖。
3. **前端量測數據登錄 404 與 500 錯誤**：
   - **問題**：路由缺少版本前綴導致部分請求報 404；重複儲存中分類代碼時直接觸發 DB 異常回傳 500。
   - **修復**：後端新增相容路由（支援 `/api` 與 `/api/v1` 雙路由），並在中分類寫入前執行 `IgnoreQueryFilters()` 唯一性防呆驗證，異常時回傳明確的 `400 Bad Request`。

## 現存待辦 (Remaining Items)
- **歷史數據封存**：當量測數據達到百萬級時，需定期將舊資料封存以維持 SPC 圖表載入效能。
- **自定義 Western Electric 規則**：提供網頁端勾選與配置各檢驗項目要啟用哪幾項西方電氣規則。
