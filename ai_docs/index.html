Project Overview

00 專案總覽與系統演進狀態

本專案為新一代智慧企業 SPC 品質分析系統，完美整合了基礎製造主檔維護、多維度檢驗項目綁定、CSV 數據批量匯入，以及具備「一鍵公式切換」的即時互動式戰情室。

已完成核心功能

  • 8 大主檔與關係映射 CRUD 升級
  • 支援 MR-Method 動態公式運算引擎
  • 戰情室即時互動與紫色識別徽章

進行中技術迭代

  • 異常單工作流 (V2 Workflow) 閉環整合
  • 戰情室 X 軸日期時間雙列顯示優化
  • 代理式文件中樞 (Agentic Docs Portal)

下一階段架構藍圖

  • 完整 Nelson 規則驗證器與動態配置
  • 管制圖進階算法擴充 (EWMA, CUSUM)
  • 產線機台自動化量測 API 對接介面

01 系統架構與資料庫 Schema

系統採用 .NET 8 Web API 作為強大後端運算引擎，搭配 Entity Framework Core 進行 SQL Server 資料庫持久化，前端則使用 Vite + Vue 3 建立極致響應速度的單頁應用 (SPA)。

1. 警報發佈 (Open)

OOS / OOC 自動觸發

當檢驗數值超出規格 (OOS) 或違反西方電氣管制規則 (OOC) 時，系統自動發佈警報至「異常通報總覽」。

2. 更新進度 (In Progress)

工程師接單處置

品管工程師前往「V2 異常流程」尋找單號，前往戰情室追溯批次歷史，並於系統填寫改善對策與進度狀態。

3. 簽核結案 (Closed)

主管審核與閉環

對策驗證有效後，於系統將狀態變更為 Closed。確保所有品質警報皆形成完整審核軌跡與閉環追蹤。
