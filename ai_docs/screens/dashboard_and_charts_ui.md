# 前端 Dashboard 與互動式管制圖 UI 設計 (Frontend Screens Architecture)

本系統前端基於 Vue 3 (Composition API + Script Setup)、Vite 與 Tailwind CSS 開發，採用充滿科技感與沉浸感的工業深色模式 (Dark Theme)，搭配高流暢度的 ECharts 視覺化組件。

---

## 1. 介面架構與路由導覽 (Screen & Component Routing)

```
mes-spc-web/
  ├── src/
  │    ├── assets/
  │    │    └── dark-theme.css        (深色主題色票與共用樣式)
  │    ├── components/
  │    │    ├── SpcControlChart.vue   (封裝好的高互動 ECharts 管制圖組件)
  │    │    ├── AlertMarquee.vue      (今日異常跑馬燈列)
  │    │    ├── RankingCard.vue       (排行榜卡片組件)
  │    │    └── ImportModal.vue       (兩階段檔案上傳與預覽對話框)
  │    ├── views/
  │    │    ├── ExecutiveDashboard.vue(首頁戰情看板)
  │    │    ├── InteractiveSpc.vue    (多功能互動式 SPC 查詢與繪圖頁面)
  │    │    ├── MasterDataConfig.vue  (料號與製程規格界限維護頁)
  │    │    └── AlertManager.vue      (異常事件與 CAPA 追蹤管理頁)
  │    └── router/
  │         └── index.js
```

## 3. `SpcControlChart.vue` 組件規格與高互動功能 (Interactive Features)

為了達到極致視覺享受與實用價值，基於 Apache ECharts 實作以下特性：
1. **深色視覺美學**：背景採用 `#121826` 深藍灰色，圖表網格線使用 `#1F2937`，文字與數值採用清晰的 `#E5E7EB`。
2. **規格線與管制線顏色區分**：
   - 規格界限 (USL / LSL)：鮮紅點線 (`#EF4444`)，代表物理或客戶合約的死線。
   - 管制界限 (UCL / LCL)：金黃虛線 (`#F59E0B`)，代表統計變異邊界。
   - 中心線 (CL)：翠綠實線 (`#10B981`)，代表製程中心。
3. **異常點警示閃爍**：若資料點帶有 `outOfControl` 或 `violatedRules`，點位符號自動轉為紅色大圓點 (`symbolSize: 12`)，並在懸浮提示框 (Tooltip) 清楚顯示違反的西方電氣規則名稱。
4. **DataZoom 拖曳縮放**：內嵌 `dataZoom` 套件，支援滑鼠滾輪順滑縮放與底部迷你導航列拖曳。
5. **Sigma 區間渲染**：支援切換顯示 $\pm 1\sigma, \pm 2\sigma$ 背景色帶 (MarkArea)，讓工程師一眼辨識資料點落點區間分佈。
